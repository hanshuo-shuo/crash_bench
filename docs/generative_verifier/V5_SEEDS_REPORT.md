## 对故事意味着什么

- **主线站住了**：在自然分布上训练、在挡住捷径的反事实孪生上测试，
  - 直接判断（A）在 3 个 seed 上都是 50%；
  - 先写位置、再用程序判定（P）在 3 个 seed 上都是 93–95%；
  - 差距 +0.44，区间很窄，不是某一个 seed 的运气。
- **A 的失败方式也很稳定**：它在每个 seed 上都塌成一个常数，只是常数的方向随 seed 变。直接判断从这些数据里学不到"看图"。
- **P 的分工也很稳定**：定位学得会（几个像素的误差），从位置推出结论学不会（自己写的结论在随机水平），后一步一直靠程序。
- **局限**（与 S4 相同，加 seed 没有改变）：
  - 1 个任务组合（object/II/task1），4 条验证源；
  - 位置真值来自仿真几何，真实机器人上需要别的来源；
  - 约束仍是虚拟的连线；
  - 选模子集是验证集的一部分（与 S3、S4 相同），读数的 1,538 行包含选模用过的 384 行；
  - 测试集没有评估。
