## 结论

**现象很稳，机制一半稳，修复不稳。**
- 做方法型论文能依靠的是：普查、配对重跑的整套设施、"这条路上带着任务身份"这个事实。
- 不能依靠的是："印记变淡导致失败"和"放大能修复"。这两条只能按下面收窄的说法写。
- 实验纪律没有问题：读法都在提交前冻结，报告数字与存档一致，预测失败的地方都如实写了。

## 各条的要害

**1 现象**
- 证据（✓ 复核）：native 在 f = 0、.5、.75 分别是 864 / 882、213 / 882、190 / 882。
- 失败全部是跑满 300 步；1,361 个失败里 810 个把旧任务做完了。
- 最大的威胁：没有"这个状态下新任务做得成"的见证。同一物体的对 162 / 272，不同物体的对 241 / 1,492（✓ 复核）。第 1 步"退回再做"正是补这个见证。
- "90 对"背后只有 10 个旧任务、98 条前缀。按旧任务分很不均匀：任务 0 是 2 / 180，任务 7 是 12 / 180（✓ 复核）。
- 完全相同的状态、种子和臂重跑，逐状态的结果并不都相同。试点五个失败格的 90 个状态上，两次重跑一致的是 73–80 个（81–89%）；成功格是 98–100%（✓ 复核）。格一级的比例是稳的（17、19、20；64、65、67），所以结论按格和任务对读，不按单个状态读。

**2 标记**
- 普查里用 γ 区分成败的 AUC：全部 0.668，同一物体的对 0.828，**不同物体的对 0.555**（✓ 复核）。
- 加到四个物理协变量之上，AUC 只从 0.713 到 0.716。
- 冻结的因果检验没过：把印记调弱到自然失败的水平，232 个里 201 个照样换过去（剂量批次 D1）。
- 放大的增益在印记最不淡的那一档最大，和"变淡是原因"的方向相反。
- γ 的定义前后不一：开环用第 12–17 层，普查用第 12–14 层。

**3 必要**
- 证据：230 / 232 → 6 / 232，失败的 224 个里 215 个做完旧任务；同样大小的随机改动 66 → 66。
- 缺的对照：把这几层换成"各指令的平均"或第三个任务的值；在别的层做同样的替换。闭环里只动过第 12–14 层和全部 18 层，而开环找到的最佳窗口是第 14–16 层。

**4 修复**
- 试点格三次重跑是 17 → 64、19 → 65、20 → 67（同一批状态和种子，不是独立重复）；普查的新前缀上是 9 → 23 / 40。
- 不按格挑选时，非试点对的全部中途状态是 374 → 429 / 1,704，+0.032，区间 [−0.001, 0.064]。
- 普查的格是用同一批 native 结果分的类，所以"失败格上的增益"偏高、"成功格上的损害"偏重。
- 放大之后的去向（✓ 复核，含试点对的失败格）：原本做完旧任务的 778 个里，424 个照旧，275 个两个都没做成，79 个换成功。
- 缺的对照：参考指令不是 A 的放大（比如沿 B − C）。现在分不开"补回变淡的路"和"放大任意指令对比"。

**5 写入者**
- "经过 MLP"不等于"由 MLP 产生"：指令只能通过注意力到达图像 token。
- 单元补测在同一个状态上排名和评估，只看开环第一个动作块，216 个状态里只有 83 个可读。
- 盲测是语言模型写解释、语言模型答题，只留出了初始布置。

1. 修复不推广：非试点对上 +3 到 +5 个百分点，区间贴着 0；多数是把机器人弄停而不是换过去；还要旧指令和第二遍。
2. 现象没有和"陌生状态"分开：物体是否相同预测成败和 γ 一样好（AUC 0.661 对 0.668）。
3. 机制的特异性对照不够：没有别的层、别的 token、别的参考指令；"必要"其实是把 A 写进去。
4. 范围：一个检查点，每个状态一个种子，10 个 Goal 任务；LIBERO-10 只有两对；Object 上起点换只有 1 / 19；OFT 和 π0 没有机制数据。
