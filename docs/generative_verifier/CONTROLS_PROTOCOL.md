# 单通路对照协议：direct 路径能否学会单一模态的标签

2026-10-18。接在 [STEP1_REPORT.md](STEP1_REPORT.md) 之后。
本文件和 `verifier_training/control_contract.py` 在 GPU 作业提交前一起提交到 Git，作为这一步的预注册。

## 1. 要回答的问题

第 1 步里，A 连 16 行都拟合不了，B 能拟合，实现检查没有发现错误。这一步回答三件事：

- direct 路径能不能学会只看文字就能定的标签（t）；
- direct 路径能不能学会只看图像就能定的标签（s）；
- 把受保护颜色先写出来再判断（A+P），是否已经足以恢复拟合。

在每一行上，原判定都等于 s XOR t。

## 2. 授权与范围

用户 2026-10-18 认可的范围：

| 对照 | 优先级 | 主要问题 |
|---|---|---|
| t：直接预测受保护颜色 | 必做 | direct 路径能否学会这个文字标签 |
| s：直接预测分隔盒颜色 | 必做 | direct 路径能否学会这个图像标签 |
| A+P：复述受保护颜色后判断 | 建议加入 | 简短的颜色复述与输出结构改动，是否已经足以恢复拟合 |
| 梯度测量 | 可后置 | 是否存在可测量的有效梯度不足或相消 |

- 这一步做 t、s 和 A+P。梯度测量不在这个作业里。
- 不读测试集，也不评估验证集；不调用 API；不做超参数搜索。

## 3. 设置

除训练目标外，其余设置都与第 1 步相同：

- 同样的 16 行（`unit_130`、`unit_067`、`unit_165`、`unit_042`），作业开始时与第 1 步的 `SUBSET.json` 逐项核对；
- 同样的样本顺序，作业开始时与第 1 步 A 的顺序逐批核对；
- 同样的超参数（Phase 2 配置逐项相等），3 个 seed，160 次更新（40 个 epoch）；
- 同一个训练循环（`fit_run.overfit`），同样的 Phase 2 编码、损失和更新代码；
- 在第 40、80、120、160 次更新后，对这 16 行做 greedy 自由生成，按该组的标签计分。

**三个训练目标**：

| 组 | 模型要输出的文字 | 标签只依赖 |
|---|---|---|
| t | `Verdict: 1`（规则保护橙色）或 `Verdict: 0` | 规则文字 |
| s | `Verdict: 1`（分隔盒是橙色）或 `Verdict: 0`；分隔盒是恰好装着目标和终点之一的那个盒子 | 图像 |
| A+P | `Protected: <颜色>`，换行，再写原来的 `Verdict: 0/1` | 两者 |

- t 和 s 走 direct 路径，判定位置与 A 完全相同，只是数字的含义换了。
- A+P 只在判定前多抄一个颜色词；颜色 token 是关键片段，判定数字仍是决定性的 token。

**作业开始时的标签检查**（16 行和全部 512 个训练行都查）：

- 每一行都满足 判定 = s XOR t；
- 同一组图的 s 相同，同一段规则文字的 t 相同；
- 在每个图像组和每个文字组里，判定都是一半可行、一半不可行。

在登录节点上用 JSON 预先核对过：512 行、256 个图像组、178 个文字组全部满足。

## 4. 判定规则（作业开始前冻结在 `config.json`）

**拟合损失**：判定数字的交叉熵。t、s 用 `direct_verdict`，A+P 用 `facts_verdict`。取最后一个 epoch（4 次更新）的平均。

**每次运行**的分类与第 1 步完全相同：

| 类别 | 条件 |
|---|---|
| 能拟合 | 第 160 次更新后 greedy 准确率 16/16，并且最后一个 epoch 的平均拟合损失 < 0.1 |
| 不能拟合 | 准确率 ≤ 10/16，或者拟合损失 ≥ 0.6 |
| 部分 | 其他情况 |

- **每个组的结论**：3 个 seed 中至少 2 个同类，就取该类；否则记为 mixed。

**t / s 的读法**（参照第 1 步：A 不能拟合，B 能拟合）：

| t | s | 记为 | 含义 |
|---|---|---|---|
| 能 | 能 | `composition_bottleneck` | 两个因子各自学得会，组合学不会；困难集中在把两者组合起来。这本身还不是梯度机制的结论 |
| 能 | 不能 | `image_relation_bottleneck` | direct 路径学不会"哪个盒子把目标和终点隔开" |
| 不能 | 能 | `text_pathway_problem` | 只看文字的标签也学不会；继续查实现、优化和输入能否分辨 |
| 不能 | 不能 | `direct_path_problem` | 两个单一模态的标签都学不会；继续查 direct 路径的实现和优化，但仍不能直接认定有 bug |
| 其他组合 | | `inconclusive` | 如实报告，讨论后再定 |

**A+P 的读法**：

| A+P | 记为 | 含义 |
|---|---|---|
| 能 | `restatement_restores_fit` | 颜色复述连同输出结构的改动足以恢复拟合；这个作业分不开这两者 |
| 不能 | `restatement_insufficient` | 只复述颜色不够，还需要 B 那样的中间包含关系 |
| 部分或 mixed | `inconclusive` | 如实报告 |
