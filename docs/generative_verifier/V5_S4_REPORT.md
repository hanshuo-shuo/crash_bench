## 一句话

- **预注册读法 `positions_ground`**：
  - P 在完整验证集（1,538 行反事实孪生）上的程序判定准确率是 **0.940**，95% 区间 [0.926, 0.952]；
  - 同样的行上，S3 的 A 是 0.501；
  - P − A = **+0.438**，以图像为单位做 bootstrap 的 95% 区间是 [+0.416, +0.461]。
- **故事线跑通了**：
  - 同样的图、同样的规则、同样的训练设置，直接判断（A）在反事实孪生上是 50%；
  - 写"在线的哪一侧"（S3 的 B）也是 50%；
  - 改为先写出物体在图上的位置、再由程序判断是否隔开（P），是 94%。
  - 两种答案都有的图上，两行全对的比例 A 是 0.3%，P 是 81%。
- **起作用的是分工**：模型负责定位，程序负责几何。P 自己写的 `Separated` 和 `Verdict` 塌成了常数（1,538 行全是"不隔开、可行"），从位置推出结论这一步，模型并没有学会。V4 的结论是"关系事实 + 程序规则"可以学会；V5 在更真实的场景里给出的是更具体的一句：要先把事实落到模型看得出来的位置上。
- **只有 1 个 seed，只看了验证集**，测试集没有碰。加 seed 和唯一一次测试评估都需要用户另行确认。

## 对故事意味着什么

- **主线**：在自然分布上训练，在挡住捷径的反事实孪生上测试。
  - 直接判断学到的是"规则 × 进度"的先验，自然布局上 0.90，反事实上 0.50。
  - 先写模型看得出来的事实（位置），再用程序判定：自然布局上 0.96，反事实上 0.94。
- **和 V4 的关系**：
  - V4 的事实是"在不在画出的彩色框里"，模型能直接学会；
  - V5 的事实一开始写成"在线的哪一侧"，模型学不会（S3、拟合诊断）；
  - 换成位置以后学会了，而且推广到挪过物体的布局。
  - 共同点是：中间事实必须是模型能从图上读出来的东西，组合交给程序。
- **要如实说明的局限**：
  - 只有 1 个 seed、1 个任务组合（object/II/task1）、4 条验证源；
  - 结论来自程序，模型自己写的结论是常数；
  - 位置真值来自仿真里的几何，真实机器人上需要别的来源（标注或检测）；
  - 约束仍是虚拟的连线；
  - 测试集没有评估。
