数据是 V4 开发数据，它的 shortcut 闸门没有通过（见 §6）。

## 结论速览

1. **主比较达到科学标准**。在锁定测试集上，B（先生成结构化事实再判断）比 A（直接判断）高 **29.7 个百分点**：
   79.7% 对 50.0%，源聚类 bootstrap 95% CI 为 [+22.3, +36.8]。
   15 个源上的精确 sign-flip 检验 p = 0.00012，Durkalski 聚类 McNemar 检验 p = 0.0005。
2. **开发里程碑没有达到**。B 的三项指标都在门槛以下：
   - 行准确率 79.7%（门槛 85%）；
   - 单元四行全对 54.2%（门槛 70%）；
   - 规则翻转一致 64.2%（门槛 90%）。

   因此 B 还不能当作安全执行门；false-feasible 率为 21.9%。
   原始测试报告曾把 oracle 诊断也算进去，误报"里程碑达成"；更正见 §5。
3. **A 是一个没有学起来的基线**。3 个 seed、3 个检查点都给出常数预测，准确率 50%；
   最后 32 步的训练判定损失为 0.70–0.71（随机水平 ln 2 ≈ 0.693），也就是在训练集上就没有拟合。
   C 的直接读法也一样。所以只能说：**在这个数据、模型和固定训练预算下**，先预测空间事实的方案更容易学会；
   不能说直接判别的方法本身不行（没有做超参数搜索，也还没排除实现问题）。
4. **C 只给出线索，不能说明机制**（2026-10-17 独立评审后修订）：
   - C 的 CoT 读法比它自己的直接读法高 12.8 个百分点，CI [+7.2, +18.3]，按预注册属于探索性结果；
   - C 的事实样本只有 B 的一半。按见过的事实样本数对齐后，C 与 B 几乎相同（验证集：512 个样本时 54.5% 对 55.6%；
     768 个时 65.1%，B 插值约 64.5%）。C 比 B 低主要是事实监督少，两个目标之间的干扰不大；
   - C 的直接分支在训练中本身也停在随机水平（判定损失约 0.69）。
     所以只能说"事实联合训练没有让直接判定学起来"，**不能**说"收益来自测试时推理"。
5. **错误全部出在两个包含关系的预测上**：
   - 576 个 B 测试判定：458 个两个关系都对、判定也对；72 个只错了"目标在内"，45 个只错了"终点在内"，判定都错；
     1 个两个都错、经 XNOR 抵消后判定正确；
   - 最终判定与"把模型自己预测的两个关系代入程序规则"**逐行一致**，规则组合没有增加错误；
   - 包含关系错误的来源可能是遮挡、投影歧义、颜色与盒子的绑定、模型表示或捷径，不能直接归到视觉编码器；
   - 关键字段准确率：目标在内 87.3%，终点在内 92.0%，四个全对 79.5%。
   - oracle 诊断是 100%，但强制写入的前缀已包含 `Separated` 一行，它直接决定判定，所以不能单独证明模型会组合关系（见 §4）。
6. **多次采样没有提高准确率**（K=16 时 −0.3 个百分点），只提高了排序能力（平均 P(1) 的 AUROC 从 0.80 升到 0.87）。
7. **超过所有基线**：
   - 固定颜色/规则读数在测试集上 AUROC 0.63–0.66；
   - Qwen 零样本 49.5–53.6%；
   - B 的合并 AUROC 0.889。
   - 在"已测捷径较弱的子集"（ENTRY × checkpoint>0）上，B 为 85.4%，读数 AUROC 只有 0.55–0.63。

## 5. 原始测试报告中的错误与更正

- **错误**：`REPORT_test.json` / `.md`（e03da26）把里程碑判为"达成"。
  原因是判定遍历了所有读法，包括 oracle_facts 诊断（强制写入正确事实后读 verdict，准确率当然是 100%）。
- **更正的依据**：预注册写明里程碑针对的是组（arm）。只有 A direct_free、B facts_free、C direct_forced、C facts_forced 四个读法有资格，它们都没达标。
- **更正的做法**：commit `4075e2d` 修了代码，并新增只读的更正步骤，写出：
  - `REPORT_test_CORRECTION.json`：原判定、更正后的判定和原因；
  - `REPORT_test_CORRECTED.md`。
- 原报告文件、所有预测和其他指标都没有改动。

## 6. 解读与限制

**按计划的结果解读表**：

| 观察到的结果 | 计划中的含义 |
|---|---|
| B > A | "加入事实监督并生成事实"这整套方法有收益 |
| C-CoT > C-直接 | 计划原先解读为"测试时显式生成事实有额外帮助"；但受事实监督量和直接分支未学起来两个因素混杂，只算线索（见结论速览第 4 条） |
| 关键事实准确率不够高 | 包含关系的预测是瓶颈；具体原因尚未分开（grounding、视觉输入、裁剪或提高分辨率都是候选） |

**限制**：

1. **数据**：V4 是开发数据，shortcut 闸门失败（validation AUROC 0.78）。不过：
   - 这些读数在测试集上只有 0.63–0.66；
   - B 在读数最弱的子集上仍有 85.4%；
   - 加上"事实对但判错"为 0，模型主要依赖的不像是摆放伪迹。

   这只是证据，不是证明：其他未测的捷径没有被排除。
2. **任务很浅**：rationale 本质是两个比特加一个 XNOR，每张图恰好只有一个分隔盒。
   结论不能外推到一般的机器人规划推理，也不能外推到真实碰撞物理。
3. **A 的失败依赖设置**：固定 LR 1e-4、384 次更新、LoRA r16，没有做超参数搜索。
   "直接判别学不会"只在这个预算内成立。
4. **样本量**：测试集只有 15 个独立源，seed 不增加独立场景；C 的 seed 间差异很大（55–72%）。
5. **安全门**：B 的 false-feasible 21.9%，离安全执行门（Phase 4）还很远。
