## 2. P 的目标

输入和 S3 完全相同：两张图、任务、规则。preflight 会逐行核对，P 的推理输入与 S3 的 A、B 逐字节相同。

```
Line: alphabet soup can | salad dressing bottle
Line points: [x1, y1] [x2, y2]
Target point: [x, y]
Goal point: [x, y]
Separated: yes
Verdict: 0
```

- **坐标**：第 1 张图（`overview_a`，448×448）上的像素，x 向右、y 向下，取整。
- **各个点**：都是桌面上的点（z = 0）。
  - 两个锚点：物体包围盒中心的正下方，顺序与 `Line:` 一致；
  - 布丁：标签计算所用的布丁材料点的正下方；
  - 篮子：篮子包围盒中心的正下方。
- **投影**：用渲染时存下的相机（`CAMERA.json` 第一个视角，MuJoCo 针孔模型）。学生图是左右翻转过的，公式是 x = (1 − nx)/2·448，y = (1 − ny)/2·448。在一张训练图上叠加投影点，已经目测核对过。
- **核对**：这几个点都在桌面这同一个平面上。平面到图像的射影变换不改变"两点在一条线的同侧还是两侧"，所以程序在图上算出的结论和世界坐标下的标签应当一致。
  - 起草时已在全部 3,409 个训练和验证行上核对：取整后的点算出的 Separated 与标签 100% 一致；没有点落在图外；布丁或篮子离线最近 15 像素，中位数约 60 像素。
  - preflight 会对每一行重新核对，有任何一行不一致就停止。
- **程序**：布丁点和篮子点严格落在两个线点所连直线的两侧，算作隔开，判 0；否则判 1。点缺失、无法解析，或两个线点重合，都按判错处理。

## 4. 读数（只看验证）

| 读数 | 定义 |
|---|---|
| R1 | 完整验证集（1,538 行）上，程序判定的准确率（主读数）；模型自己写的 Verdict 的准确率（次读数） |
| R2 | 孪生图全对率（程序判定） |
| R3 | 四个点各自与真值的像素距离：中位数、15 像素内比例、30 像素内比例；程序判定与模型自写判定的一致率 |
| R4 | 验证自然（79 行）上的程序判定准确率 |
| R5 | 训练拟合子集（256 行）上的程序判定准确率 |
| R6 | 零样本定位：3B 基座和本地 Qwen3-VL-32B 在选模子集的 192 张图上（只给第 1 张图），对布丁、篮子和规则里的锚点各给一个点，读出以下三项：<br>- 命中率：落在物体投影包围框内，框向外放宽 4 像素；<br>- 到桌面点的距离；<br>- 用这些点跑程序得到的 384 行判定准确率 |

- **不确定性**：以图像为单位做 bootstrap，给出 95% 区间（1,000 次，seed 1014）。
- **R6 的坐标约定**：
  - 3B（Qwen2.5-VL）：448 输入图上的绝对像素；
  - 32B（Qwen3-VL）：0–1000 的相对坐标，乘以 0.448。
  - 两个模型都同时记录按另一种约定算出的命中率，仅作诊断。
  - 零样本指的是物体本身，不是桌面点，所以它的程序判定只作参考。

## 5. 读法（事先写定）

设 P 为 R1 的程序判定准确率，A 为 S3 的 A 在同一验证集上的准确率（0.501），区间指 P − A 的图像 bootstrap 95% 区间。

| 读法 | 条件 | 含义 |
|---|---|---|
| `positions_ground` | P ≥ 0.65，且 P − A ≥ 0.10，且区间下限 > 0 | 先写位置让模型落到了图上，A 没有。故事线成立：下一步 3 个 seed，然后测试评估一次（都需另行确认） |
| `positions_fail` | P ≤ 0.60 | 写位置也没让模型看对；如实报告，收尾 |
| `unclear` | 其余情况 | 报告后讨论 |
