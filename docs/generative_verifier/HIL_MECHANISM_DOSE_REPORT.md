## 能说什么、不能说什么

**能说**（π0.5 `pi05_libero`，LIBERO-Goal，闭环，冻结读法）：
1. **动作专家第 12–14 层图像 token 上的 B − A 是中途切换必须经过的。** 原本能换的 232 个状态里，只把这三层图像 token 的 K/V 换回旧指令的值，切换从 230 降到 6。同样大小的随机 K/V 方向没有作用，动作上匹配的推动只降到 74。
2. **拿掉它得到的失败，和自然失败一个样子**：96% 去把旧任务做完。加上前两批"补强它能救回失败格"，这条路两个方向都有闭环证据：拿掉就换不过去，补强就能换过去。
3. **在 t = 0 这三层同样必要。** 换指令发生在开头时，拿掉它们也几乎全部失败。Goodfire 在 t = 0 做的是开环定位，这是闭环的对应结果。
4. **剂量曲线是陡的**：B − A 剩一半时大多数还能换，剩四分之一时只剩三成。任务越往后、离边界越近，越扛不住调弱。

**不能说**：
- **不能说"自然失败就是因为这条路变淡"。** 把原本能换的状态调到自然失败的水平（剩一半），切换只少 12.5%，判 `nonspecific`；只有 f = .75 和本来就在边界上的格明显受影响。自然失败还要别的因素。
- **D1 的特异性没有合适的对照**：act0 按 wk0 配大小，比 wk50 大约 2.5 倍。和 wk50 一样大的动作推动会怎样，本批次没测。K/V 上的 rnd0 指向"方向是特异的"，但只在 54 个试点状态上、只作报告。
- **"必要"只在原本能换的格上测了**：Goal 一个套件、5 对任务、一个检查点。留出成功格来自修复批次，层窗口是在试点对上选的。
- **wk0 不是"关掉"这条路**，而是让这三层读到 A 的图像 K/V。它说明新指令必须改写这里，不说明这三层之外没有别的路：9→2 .5 在 wk0 下还有 5/16 换成功。
- **干预要知道旧指令 A**，每次推理多算一遍前缀。
