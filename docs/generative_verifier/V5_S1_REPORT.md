## 盲看

两轮都在读任何标签之前写定并提交：
- 第 1 轮只看两张斜视图，[v5_s1_blind_review_pass1.json](../../verifier_dataset/reviews/v5_s1_blind_review_pass1.json)，提交 `f72d254`；
- 第 2 轮加上俯视图，[v5_s1_blind_review_pass2.json](../../verifier_dataset/reviews/v5_s1_blind_review_pass2.json)，提交 `4e5092b`。

| 读数 | 第 1 轮（两张斜视图） | 第 2 轮（加俯视图） |
|---|---:|---:|
| R1 判定回答率 | 40/40 | 40/40 |
| R2 判定准确率 | 40/40 | 40/40 |
| R3 T：回答率 / 准确率 | 40/40 / 40/40 | 40/40 / 40/40 |
| R3 G：回答率 / 准确率 | 40/40 / 40/40 | 40/40 / 40/40 |
| R4 锚点辨认 | 20/20 | 20/20 |
| 事实置信度为"高"的判断 | 25/40 | 36/40 |

**读法**：
- 判定 `relation_visible`，事实 `facts_readable`。
- **俯视图**：回答率和准确率在第 1 轮已经是 1.0，第 2 轮没有提高。按读法，S2 用两张斜视图。俯视图唯一的作用是让机器人底座的位置更确定，事实置信度"高"的判断从 25 个增加到 36 个。

**判断方法**：
- 在图上估计锚点、布丁和篮子的地面落点，用二维叉积判断落在连线哪一侧，并在另一张图里核对。
- 机器人一侧在斜视图里靠可见的底座法兰确定；看不到法兰时，看机械臂从哪个方向伸进画面。
- 不确定的地方（第 1 轮事实置信度为"中"）集中在三种情况：底座在画面外、两个锚点靠得很近、锚点被机械臂挡住。这些情况最后也都答对了。

**局限**：
- Claude 事先知道每个单元恰好一条分隔、一条不分隔（协议写明）。
- 本次会话早些时候，Claude 读过自然布局的几何（机器人底座在世界坐标 (-0.60, 0)），也看过一张训练源的 smoke 渲染图。盲看时没有用世界坐标。
- 20 个单元、4 条源，样本小。
- Claude 是前沿视觉语言模型，不是人工审阅，也不代表训练后的 3B 学生能做到。
- 渲染时刻的余量把终点当成 6 cm 的盒子来算，最小值是 4.8 cm，比 S1a 用点算出的余量小。标签一致不受影响。
