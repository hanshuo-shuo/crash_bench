## 1. 重点

### 1.1 现在在哪

- **现象站住了**：LIBERO-Goal 全部 90 个有序对，中途换指令 22.8% 换得过去，从起点换是 98.0%。同一物体的对 59.6%，不同物体的对 16.2%。（[普查报告](HIL_MECHANISM_CENSUS_REPORT.md)）
- **这个现象别人也报告了**：Causeway 在同一个 π0.5、同一个 LIBERO-Goal 上，不干预是 26.0%。
- **我们现有的修复当不了方法**：放大 2 倍在全部状态上是 22.8% → 26.7%。它多数时候只是把旧任务打断，手臂并没有去新任务那边（11-14 事后分析）。
- **撤回一句话**：11-12 写的"失败有两层：没听见，和听见了但做不了"没有证据。放大后"两个都没做成"的运行里，到过新任务干活位置附近的只有 26%，和压根没理新指令的运行（24%）一样。
- **普查分不开两种解释**："不听新指令"和"从这个状态做不了新任务"。第 1 步补这个见证。
- **别人做到哪**：换任务，Causeway 不训练做到 61.6%，ReSteer 靠训练；停下，ELLSA 和 VITA-E 做到 94–100%，但都是专门的结构。细节见附录 A。

### 1.2 故事线（方向 b）

1. **问题**：一个扁平的 VLA（没有上层模型）在任务中途基本不理会新的指令。换成另一个任务大多失败；"停下""回原点""别做了"照做不到 1%。（已有：普查、HIL 套件）
2. **原因的线索**：训练数据里每一局只有一条指令，从头到尾不变。模型在任务中途的状态上没见过"指令和正在做的事不一致"。（推断，不是结论；第 1 步给一半证据）
3. **方法**：一次后训练。老师数据全部由脚本动作加模型自己已有的技能生成，不用人采数据，不改结构，不加上层模型。同一份数据教会它几种中途指令：换任务、回原点、停下、放下。（第 2 步，没批准）
4. **结果**：换任务的成功率要比 Causeway 和 ReSteer 式的对照高；其余几种指令照做；原任务不掉；推理不变慢。

### 1.3 和别人比，哪里不一样

按 11-14 读全文后的情况，如实写：

| 我们想主张的 | 别人有没有 | 还剩多少 |
|---|---|---|
| 换任务做得更好 | Causeway 61.6%（不训练），ReSteer（训练，做法和我们的第 2 步几乎一样） | 要靠数字赢 |
| 没见过的任务对也能换 | ReSteer 没测 | 有，但 Goal 只有 10 个任务，没见过的对里两个任务单独都见过 |
| 不用人采数据、推理零开销 | ReSteer 也是 | 不算差异 |
| 停下、回原点、放下 | ELLSA、VITA-E 能停，靠专门结构；Hi Robot 靠上层模型。Causeway 和 ReSteer 不覆盖 | "同一个扁平模型、同一次后训练"是新的；单看"会停"不新 |
| 几种指令一起训练，换任务本身更好 | 没人测 | 假设，没有数据 |
| 同一物体的对 | Causeway 排除了 | 我们有数据（59.6%） |

所以论文的主数字是换任务，其余几种指令是覆盖面。

### 1.4 门槛和保底

- 全部 90 对上明显超过 Causeway 的 61.6%（比如 75% 以上），没见过的对也接近，原任务不掉，其余指令照做 90% 以上：可以投主会。
- 换任务只到 50–60%：和已有工作持平，靠覆盖面写，档次降一级。
- **保底**：现有结果加第 1 步，写一篇分析型论文，讲中途指令为什么不被执行、为什么通用引导没用、回到入口状态有没有用。
- 这些门槛是 Claude 的估计。训练还没跑过，没有数据说明能到多少。

### 1.5 风险

1. **"教了就会"不稀奇**。"停下"这类话模型从没学过，从头说也是 0 / 118。论文里必须有"策略外的关键词加脚本"这一行基线，并说明模型内解决多出了什么。
2. **脚本退回如果已经很高**，训练出来的模型必须比它多点什么，比如同一物体的对不用退、手里的东西放稳而不是扔下。
3. **只有仿真和一个模型**。Causeway、ReSteer、Hi Robot、VITA-E 都有真机。没有真机至少要加第二个模型或第二个任务集。
4. **训练的工程没打通**：openpi 的训练在 Quest 上没跑过。

### 2.3 第 1 步：退回再做

方案见 [HIL_RETREAT_PROTOCOL.md](HIL_RETREAT_PROTOCOL.md)。换指令时先用脚本放下手里的东西、退回本局的起始位姿，再让 π0.5 自己做新任务，在普查的 1,764 个中途状态上跑。

11-14 改了一处：U3（退回后印记是否恢复）从读数降为只报告。原因是 π0.5 没有记忆，印记完全由当前画面决定，手臂回到起始位姿后印记接近起点是意料之中，说明不了因果。

估计：代码 1 天，正式批次约 25–30 GPU 小时。

### 2.4 第 2 步：后训练（设计草图，没批准）

**教哪几种指令：**

| 指令 | 老师数据怎么来 | 纳入吗 |
|---|---|---|
| 换任务 | 脚本退回，再让模型自己做 B，成功的留下，整条标成指令 B | 主结果 |
| 回原点 | `home` 臂的脚本段 | 纳入 |
| 停下 | 保持不动 | 纳入 |
| 别做了（放稳再退） | 要新写"降到桌面再松手"的脚本，这是新的脚本动作，要用户点头 | 纳入 |
| 放回原处 | 模型没有记忆，看不到原位置 | 不纳入 |
| 中途加规则（别越线） | 需要空间判断，属于 verifier 那条线 | 不纳入，写成局限 |

- **数据**：第 1 步的成功轨迹加上面几种。任务对分成训练对和留出对。评测换一批初始布置（普查用了 0–9，评测用 10–19，要新跑 100 条前缀）。
- **训练**：从 `pi05_libero` 检查点出发，原 LIBERO 数据和新数据混合，标准的行为克隆损失。ReSteer 的配置可作参考：全量微调，2,000 步，批大小 128，LIBERO 和新数据 1 : 3。
- **臂**：
  - T1 只教换任务（相当于 ReSteer，是对照）；
  - T2 几种指令一起教（我们的方法）；
  - T3（可选）T2 上把优化器换成 SAM（Flatness 的做法）。
- **"保住印记"的损失不再是主要差异点**。依据弱：印记在不同物体的对里分不出成败（AUC 0.555）。只有第 1 步里退回后的印记能在不同物体的对里区分成败，才把它当一个可选的消融臂。
- **评测**：
  - 换任务：普查的协议，全部对和留出对；
  - 回原点、停下、别做了：HIL 套件阶段 2 的判定，代码现成；
  - 原任务成功率、推理耗时。
- **基线**：不干预；策略外的关键词加脚本；脚本退回再做（第 1 步）；Causeway 的论文数字（设定不同，并排列出时注明）。
- **判停**：T1、T2 在留出对上都不超过不干预 + 15 个百分点，就转保底。
- **算力**（估计，没有实测）：每个臂微调几个小时到一天（A100 80 GB）；普查规模的评测每个臂约 25 GPU 小时，比较臂时先用三分之一的状态。
- **要先确认的工程问题**：openpi 的 JAX 训练在 Quest 上能不能跑；运行记录怎么转成训练数据的格式；80 GB 显存放不放得下全量微调，放不下就冻结一部分或用 LoRA。
