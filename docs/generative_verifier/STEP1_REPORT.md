## 结论速览

- **按预注册的决策表**，结论是 `implementation_suspect`：
  - A 连 16 行都拟合不了，3 个 seed 都停在 50%，判定损失约 0.69；
  - B 3 个 seed 都在第 80 次更新时拟合了 16/16；
  - A 在 512 个训练行上停在随机水平。
- **按协议做了规定的检查**：逐项检查 direct 目标的编码、掩码和损失，**没有发现实现错误**（§3）。
- **目前最合理的解释**（还没有验证）：
  - 反事实平衡的构造，让直接标签成了"规则颜色词 × 图像"的纯交互：任何单一特征和标签的相关都是 0；
  - 从没有相应先验的模型出发，梯度下降几乎拿不到一阶信号，这和用梯度学奇偶函数（parity）的困难是同一类问题；
  - B 的事实把这个交互拆成了几个各自有一阶信号的小步骤。
  - 这个解释和现有数据一致，但本次实验还不能把它和"只在 direct 路径上出现、目前没看到的 bug"区分开（§4）。

## 3. 按协议做的实现检查（CPU，无训练）

在一行训练数据上逐个 token 解码，并对 A 与 B 各做一次损失移位检查：

- **A 的监督 token** 正好是 `Ver` `dict` `:` ` ` `0/1` `<|im_end|>`，判定掩码只覆盖数字这一个 token。
  B 的判定部分与 A 相同，只是前面多了四行事实。
- **损失移位正确**：把 logits 设成在每个位置都完美预测下一个金标 token，A 和 B 的总损失与判定损失都为 0。
- **输入**：A 与 B 的推理输入完全相同。Phase 2 preflight 已逐行核对；本次作业又核对了 512 行的哈希。
- **两个通路都能工作**：
  - B 能学会依赖图像的事实，例如"目标在受保护盒里"，所以图像信息确实进入了语言模型；
  - B 能从规则文字里抄出受保护的颜色，所以文字通路也在工作。
- **同一个图像对的两行**，规则文字只差一个颜色词（orange ↔ purple），标签相反。

**结论**：没有找到会让 A 学不到东西、而 B 不受影响的编码、掩码或损失错误。

## 4. 解读与限制

- **构造上的原因**：
  - 每个四行单元里，单看规则颜色词、单看图像（两种配色）都给不出任何标签信息，只有两者的交互可以；
  - 模型从先验预测（损失 ln 2）出发时，各行梯度里的一阶成分正好互相抵消，与 parity 一类问题相同；
  - B 的事实把交互拆开：先抄颜色（文字），再判断"目标或终点在这个颜色的盒子里吗"（以前面写出的颜色为条件的感知），最后在显式事实上做 XNOR。每一步都有一阶信号。
- **对 Phase 2 结论的影响**：
  - "B − A = +29.7 个百分点"仍然成立；
  - 但 A 的 50% 更像是"这种平衡构造下直接判别在当前预算内学不起来"，而不是"直接判别比较弱"。
  - 这与 Astra 的评审一致：A 是一个没学起来的基线。
  - 这也和"中间步骤监督让原本学不会的组合函数变得可学"的已有理论结果同向。在写入报告之前，需要先核对具体文献。
- **还不能排除的情况**：
  - 只出现在"判定数字紧跟 prompt"这条路径上、目前没看到的问题；
  - 或者 A 只是学得非常慢，160 次更新、学习率 1e-4 不够。
- **预注册规则没有覆盖**"检查后没发现问题"之后该做什么，下一步需要用户决定。

## 5. 可选的下一步（都需要用户批准新的训练）

在同样的 16 行、同一条 direct 编码路径上，只改标签或训练预算：

| 对照 | 标签 / 设置 | 回答的问题 |
|---|---|---|
| 文字标签 | 受保护颜色是否为 orange（只看文字） | direct 路径能否学会依赖文字的标签 |
| 图像标签 | 目标是否在 orange 盒子里（只看图像，与规则无关） | direct 路径能否学会依赖图像的标签 |
| A 训练预算 | 原标签，640 次更新（4 倍） | A 是学得慢还是学不会 |

- **怎么读结果**：
  - 两个单通路标签都很快学会、原标签仍学不会，就支持"交互难学"的解释；
  - 单通路标签也学不会，就说明 direct 路径确实有问题。
