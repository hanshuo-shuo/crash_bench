## 对故事意味着什么

- **主线在没见过的测试源上站住了**：在自然分布上训练、在挡住捷径的反事实孪生上测试，
  - 直接判断（A）在 3 个 seed 上都是 50%，测试与验证一样；
  - 先写位置、再用固定代码判定（P）在 3 个 seed 上都是 92–94%，比验证只低不到 1 个百分点；
  - 差距 +0.43，区间很窄，下限离 0 很远。
- **失败方式和分工也在测试集上原样出现**：A 塌成常数；P 定位学得会，从位置推出结论学不会，后一步一直靠代码。
- **局限**（与加 seed 相同，测试没有改变这些）：
  - 1 个任务组合（object/II/task1），4 条测试源；测试源和训练源是同一个任务的不同初始状态，不是新任务；
  - 位置真值来自仿真几何，真实机器人上需要别的来源；
  - 约束仍是虚拟的连线；
  - P 比 A 多拿了位置监督，比较的是"给什么监督、谁来做最后一步"，不是同等信息下的两种模型；
  - 测试自然只有 80 行，只作参考；
  - 测试集已经用过这一次，以后不能再拿它选模或重评。
