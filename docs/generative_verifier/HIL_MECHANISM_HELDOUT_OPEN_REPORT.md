## 能说什么、不能说什么

**能说**（π0.5 `pi05_libero`，开环，第一个动作块，存好的阶段 1 输入）：
1. **接口位置**：在 LIBERO-Goal、LIBERO-10、LIBERO-Object 的 7 个可读留出对上，动作专家在 t = 0 都从第 14–16 层读 B（最佳 3 层窗口 E 0.67–0.85），单层峰值第 14 层（一对在第 16 层）。试点和 Goodfire 的定位推广到另外两个套件。
2. **印记变淡**：留出对的失败格里，第 12–17 层图像 token 上的 B − A 印记降到 f = 0 的 0.55 倍，成功格保持在 1.13 倍；文字 token 上降得少得多。试点的描述性发现推广到三个套件；有两格例外。
3. **不是换错了窗口**：修复弱的两对在 t = 0 也走第 12–14 层图像路，接住的比例和试点对一样；修复有效的两对反而偏到第 14–16 层。
4. **开环预测不了闭环**：在 13 个失败格上，开环下修复对第一个动作块的推动、第 12–14 层图像窗口的 E，都不能预测闭环修复的增益。以后选窗口、定剂量必须在闭环里做。
5. **两个套件的共同特点**：LIBERO-10 和 Object 的中途切换几乎不改变第一个动作块（A/B 差 1–2 个噪声底），Goal 是 3 个以上。

**不能说**：
- **不能说"第一个动作块没东西可推"就是修复弱的原因。** LIBERO-10 0→1 也一样，修复却有效。修复为什么在 1→0、Object 上弱，本批次解释不了。
- **H1 的 `elsewhere` 很勉强**：8→7 是 0.39，离门槛 0.4 只差 0.01；两对的最佳窗口都只是往上挪了两层（第 14–16 层）。
- **H3 的格很少**，且留出的格每格只有 1–4 个可读状态，格中位不稳。ρ 的区间很宽（−0.59 到 0.31），"预测不了"是指这里看不到正相关，不是证明了无关。
- **图像 γ 与增益正相关只是报告**（0.48 [0.19, 0.69]），没有事先写成读法。
- **范围**：一个检查点，第一个动作块，开环；8 个留出对，LIBERO-Spatial 没有切换分支。
