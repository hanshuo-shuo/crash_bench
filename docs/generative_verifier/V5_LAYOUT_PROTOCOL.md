# V5 反事实布局协议（smoke）

2026-10-24 写定，在任何反事实布局运行之前冻结。用户 2026-10-24 在三个方向中选了第 3 个（"3吧"）。
背景见 [V5_C0_REPORT.md](V5_C0_REPORT.md)，总协议见 [V5_COLLECTION_PROTOCOL.md](V5_COLLECTION_PROTOCOL.md)。

## 这一步为故事回答什么

故事的测试需要这样的孪生：同一张图配两条规则，一条分隔、一条不分隔；文字和进度都猜不出答案；图上又看得清。
固定布局给不出这样的样本（C0）。反事实布局的做法是：

- 把机器人和被搬运物体碰不到的锚点物体挪到桌上别的位置；
- 动作带原样回放；
- 让同一任务、同一条规则的标签随布局变化。

训练用自然布局，测试用反事实布局。直接判断如果学的是文字或进度捷径，到测试布局上就会失效。

这个 smoke 只回答一件事：这样构造出来的布局，是否大多仍能得到合法的见证，并且能产出看得清的孪生。

## 构造

- **源**：C0 的 67 条 V4 源（开发用），按 `sha256(源|v5-layout-smoke)` 排序，每个 family 取前 2 条，共 8 条。
- **每条源 4 个布局**，种子为 `sha256(源|布局编号|v5-layout)`。
- **可移动的锚点**：在规范初始状态下：
  - 在场；
  - 符合 V5 锚点规则（不在任务文本里、不是目标或终点、没有相像物体等）；
  - 有自由关节。
  炉灶、柜子、酒架这类固定件留在原处，仍可作锚点。
- **摆放**：每个布局把所有可移动锚点重新摆放，高度和朝向不变。
  - **范围**：规范初始状态下所有在场物体中心的包围盒，向外扩 10 cm。
  - **与其他物体**：水平包围圆之间至少留 2 cm。
  - **与目标路径**：离源轨迹上目标材料点的水平路径至少 r + r_target + 6 cm（r 是包围圆半径）。
  - **与终点**：离终点区域至少 r + 4 cm。
  - 拒绝采样最多 200 次；采不到就留在原处。
- **回放**：从规范初始状态出发，先摆好锚点，再原样执行源的动作带。

## 见证核验（代替逐步哈希一致）

在反事实布局里实际回放出来的轨迹就是见证，必须同时满足：

1. 结束时原生任务谓词成功；
2. 每个积分子步上，被挪动的锚点只和桌面或地面接触；
3. 被挪动的锚点在整条轨迹中水平位移不超过 1 cm；
4. 机器人不接触 SafeLIBERO 障碍物（与 V4 的接触合同一致）。

任何一条不满足，这个布局就整个作废，并记录原因。另外报告目标材料点路径相对源路径的最大偏差，只作参考，不作门槛。

## 标签

与 C0 相同（`v5_trace.rows_from_trace`）：
- 只用两物体连线模板；
- 用 checkpoint 时刻的几何；
- 余量 ≥ 5 cm + 0.1 × 抬起高度；
- 可行行必须在之后的回放中不越线。

## 读数

| 读数 | 含义 |
|---|---|
| R1 合法率 | 合法布局 / 全部布局 |
| R2 静置孪生 | 合法布局里，目标还放在桌上（抬起 < 5 cm）的 checkpoint 上，同时有一条分隔、一条不分隔的规则，且余量都达标。报告单元数，以及每个合法布局的平均数 |
| R3 只看文字的上限 | 所有反事实行按（任务，规则）分组的多数类比例 |
| R4 严格层孪生 | 按"文字 × 进度段"分组两种标签都有的孪生单元数 |
| R5 路径偏差 | 目标材料点相对源路径的最大偏差（参考） |

**读法**：R1 ≥ 0.5、R2 每个合法布局平均 ≥ 1、R3 ≤ 0.80，三条同时满足时记为 `layout_design_viable`。下一步是在新的单元上做渲染和盲看（Claude 没见过的单元）。否则记为 `layout_design_insufficient`，按作废原因修改摆放规则。

## 资源

`short` CPU 数组作业，4 个分片，32 次回放，预计 20 分钟内。不渲染、不训练、不调 API，不产生数据集行。

## v2（看到 v1 结果后修改，运行前冻结）

- **修改 1**：反事实布局里，只保留至少涉及一个被挪动锚点的规则。锚点都没动的规则不随布局变化，属于自然布局那一部分。
- **修改 2**：叠在一起的物体（障碍物和它的底座，盒子和放在上面的碗）作为一个整体挪动。条件：
  - 每个成员都有自由关节；
  - 不含目标或终点；
  - 不碰机器人；
  - 对外只接触桌面或地面。
  "被挪动的锚点只接触支撑面"这条核验相应放宽为：只接触支撑面或同组成员。
- **修改 3**：种子改为 `sha256(源|布局编号|v5-layout-v2)`。源与 v1 相同（8 条）。
- **新增门槛 R6 多样性**：静置孪生至少来自 6 条源、3 个 family。
- **读法**：R1 ≥ 0.5、R2 ≥ 1、R3 ≤ 0.80、R6 同时满足时记为 `layout_design_viable`，否则记为 `layout_design_insufficient`。
