## 对 S3 结论的影响

- **排除了"编码或管线有问题"**：B 能把 16 行背到 100%、64 行背到 94–98%，梯度能把事实写进模型。
- **"没练够"的解释变弱了**：
  - 32 张图练 20 个 epoch、背到 95% 以上，在别的图上仍是查表水平；
  - S3 用 900 张图练 1 个 epoch，也是查表水平。
  - 两种训练方式都没有学出能迁移的读法。加到 3 个 epoch 不能排除会好转，但目前没有任何迹象。
- **背得比 V4 慢**：V4 的事实是画在图上的彩色框，模型很快就能背；V5 的事实要在两张斜视图里判断一条看不见的线，同样的模型背得慢得多。这和"感知是瓶颈"一致。
