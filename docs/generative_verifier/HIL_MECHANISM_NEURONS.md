## 1. 问题

已知：
- **开环**：t = 0 时，任务主要经图像 token 读入。指令在 VLM 第 4–13 层经双向注意力写进图像 token，动作专家在第 12–16 层读走。
- **闭环**：在失败格里，把动作专家第 12–14 层图像 token 上 K/V 的 B − A 差放大到 2 倍，切换从 17/90 升到 64/90。
- **修复批次**：在动作上推一把替代不了这个放大（21/90 对 65/90）。

所以第 12–14 层图像 K/V 上的 B − A 差，是切换的一个因果环节。P4 往上游追一层：这个差是谁写进图像 token 的？

1. **路径**：文字只能经注意力进入图像 token，MLP 是逐 token 的。那么图像 token 上 B 的信息，是由注意力直接搬到位，还是要经 MLP 神经元加工？只换 MLP 能补回第 12–14 层图像 K/V 上 B − A 差的几成？
2. **稀疏度**：MLP 那一份，能否由少量神经元承担？
3. **中途变淡**：在换不过去的格里，这些神经元是否不再区分 B 和 A？
4. **因果**：在闭环里，只改这些神经元，能否像 amp2 那样救回切换（充分性）？在原本能换过去的运行里，把它们压回 A 的值，是否就换不过去（必要性）？配同层随机神经元和随机方向的对照。
5. **解释**：前 10 个神经元能否用一两句话描述，并且在留出的状态和指令上，让盲测者据此预测出它们的激活？

## 2. 模型与记号

- **VLM**：Gemma 2B，18 层，每层 GeGLU 隐藏单元 16,384 个：h = gelu(x·W_gate)·(x·W_up)，输出为 h·W_down。
- **钩子层**：动作专家读第 12–14 层（窗口 W）的前缀 K/V。一个 token 在第 L 层的 K/V 只由它在第 L 层输入处的残差决定，所以能影响 W 的是 VLM 第 0–13 层。钩子装在这 14 层上，共 229,376 个神经元。
- **图像行**：两张有效图像的 512 个 token（第三个相机槽被掩掉，不算）。所有钩子只作用在图像行上，文字 token 不动。
- **每个状态**：与开环 P1 相同。
  - SW 分支存的切换时刻策略输入，A = 原指令，B = 新指令。
  - 未干预的 A 运行、B 运行，记下每层图像行上的 MLP 隐藏值 h_A、h_B，和注意力输出 a_A、a_B。
- **接口差**：G = 在 W 的图像行上，B 运行与 A 运行的 K、V 之差（float32，K、V 拼在一起）。
- **恢复比例 ρ**：在 A 运行里做某种替换，得到 W 上的图像 K/V 为 KV_X，则 ρ(X) = ⟨KV_X − KV_A, G⟩ / ‖G‖²。
  - 0 表示没动；1 表示 W 上图像 K/V 的 B − A 差全部到位。
  - 替换方式：选中的神经元在图像行上取 B 运行的值（patch-in），其余照常计算。
- **恒等式**（工具核对用）：
  - 把第 0–13 层图像行上的全部 MLP 隐藏值和全部注意力输出都换成 B 的，图像行的残差就逐位等于 B 运行的，所以 ρ = 1。
  - 只换全部注意力输出也是 ρ = 1。MLP 是逐 token 的，注意力是文字进入图像行的唯一通道，所以注意力输出一旦是 B 的，后面的 MLP 也就算出 B 的值。
  - 反过来，只换 MLP 不是恒等式：后面的注意力仍读 A 的文字。
- **归因（AtP）**：在 A 运行处，对每个神经元求 s = Σ_图像行 (h_B − h_A)·∂ρ/∂h。这是一阶近似，只用来粗筛；读数全用真实替换。

## 4. 测量

### 4.1 开环（GPU，只推理，存好的输入）

**筛选**（发现集，每对 10 个状态）：
- 每个状态算全部 229,376 个神经元的 AtP 分数；
- 每对按 10 个状态的平均分（有符号，正 = 推向 B）排序，得到每对的排名表；
- 取前 k 名，k ∈ K = {10, 30, 100, 300, 1000, 3000, 10000}。

**随机集**：对每对、每个 k，在同样几层、按同样的逐层个数，从不在前 k 名里的神经元中均匀抽取。种子由对和 k 定。

**每个状态测量**（全部 240 个状态，用该状态所属那一对的排名表）：
- **路径**：
  - ρ_mlp：第 0–13 层全部 MLP 隐藏值换成 B 的；
  - ρ_full：MLP 和注意力都换；ρ_attn：只换全部注意力输出。两者都是恒等式，应为 1；
  - 逐层 ρ_mlp[l]、ρ_attn[l]：只换第 l 层的全部 MLP，或只换第 l 层的注意力输出。
- **稀疏度**：ρ_top(k)、ρ_rand(k)，k ∈ K；前 10 名逐个单独替换的 ρ。
- **激活差**：
  - D_k = 前 k 名在图像行上 ‖h_B − h_A‖；
  - D_all = 第 0–13 层全部神经元的 ‖h_B − h_A‖；
  - ‖G‖。
- **动作**：对上面每种替换，用 4 个噪声种子算动作块，求 E（同 P1：path 朝 B 动了几成）。只报告。
- **档案**：对三对前 10 名的并集 U（至多 30 个），在 14 条指令下算图像行上的平均激活和最大激活，以及最大值所在的 token。
  - 14 条指令：LIBERO-Goal 全部 10 条任务指令、空指令、随机串、STOP、RETURN。
    - 随机串用语言消融的 `random_prompt(init)`；
    - STOP = "stop moving the robot arm now and hold still"；
    - RETURN = "stop and move the robot arm back to its starting position"。
  - 发现集上另存 A、B 两条指令下的逐 token 激活图，供写解释。

### 4.2 闭环（GPU，重跑阶段 1 SW 分支，同闭环检验）

**神经元集**：
- 每对的 S = 前 k* 名，k* 按读法 N1（第 6 节）由开环正式批次定；没有 k* 时用 10,000。
- R 是同层同个数的随机集，种子由对定，与开环的随机集不同。

**臂**（每次请求都在同一观测上先算 A、B 两遍未干预的前缀，得到 h_A、h_B；再在 B 运行里改图像行上的隐藏值，重新算前缀，然后去噪）：

| 臂 | 做法 | 用在 |
|---|---|---|
| native | 什么都不动 | 全部 |
| amp2 | 第 12–14 层图像 K/V 沿 B − A 放大到 2 倍（同闭环） | 失败格 |
| nrn2 | S 上取 h_B + 1·(h_B − h_A) | 全部 |
| nrnrand2 | R 上取 h_B + c_l·(h_B − h_A)；c_l 使每层改动的范数等于 nrn2 在 S 上该层的 | 失败格 |
| nrndir2 | S 上取 h_B + δ；δ 为随机方向，每层范数同 nrn2 | 失败格 |
| mlpall2 | 第 0–13 层全部神经元取 h_B + 1·(h_B − h_A) | 失败格 |
| nrnout | S 上取 h_A，即把 S 压回旧指令的值 | 成功格、起点格 |
| nrnoutrand | R 上取 h_B − c_l·(h_B − h_A)；c_l 同上，使每层改动的范数等于 nrnout 的 | 成功格、起点格 |
| mlpallout | 第 0–13 层全部神经元取 h_A | 成功格、起点格 |

- 噪声与闭环检验相同：同一状态各臂共用，每次请求与 openpi `Policy.infer` 的取法一致。
- 运行数：
  - 失败格 90 个状态 × 6 臂 = 540；
  - 成功格加起点格 108 个状态 × 5 臂 = 540；
  - 正式共 1,080 次。smoke 共 120 次（初始布置 0、1）。

### 4.3 盲测（CPU，加一个新开的子代理）

1. **写解释**：Claude 只看发现集（初始布置 0–9）的档案，为 U 里每个神经元写一两句英文解释，说清它在哪些指令、哪些进度下激活高，哪些相近的指令下不高。解释在打分前提交。
2. **出题**：
   - 每个神经元从读数集（初始布置 10–19）它所属那一对的状态里，按固定种子抽 24 对题；
   - 每题两项，每项是"在做任务 A、进度 f 时，指令换成 X"；随机串的项写成"一串由 A–F 和 + 组成的随机字符"，不给具体字符；
   - 两项的真实平均激活之差小于该神经元在发现集上取值范围的 10% 的，不出题。这是用真值去掉近乎平局的题，事先写定。
3. **作答**：新开一个子代理，只给解释和题目，不给仓库路径、真值和档案，让它对每题判断哪一项激活更高。
4. **平凡基线**（程序算，不需要作答者）：哪项的指令与 B 共有的词多，就判哪项高；词数相同时，指令就是 B 的那项高；仍相同时按种子掷硬币。
5. **打分**：每个神经元的正确率，和 Wilson 95% 下界。

## 5. 工具核对（开环 smoke 和正式都要过）

开环 `tool_ok` 需要以下全部成立：
1. 每个状态的 B 输入哈希等于原运行记录的；
2. **空替换**：ρ = 0，动作与 A 逐位相同；
3. **恒等式**：每个状态 |ρ_full − 1| ≤ 1e-3，|ρ_attn − 1| ≤ 1e-3；
4. **钩子不改模型**：不选任何神经元时，挂钩子的前缀算出的 K/V 与原生前缀（`patching._cache`）的最大差 ≤ 1e-2；A 的动作与 openpi `Policy.infer` 的 path 差中位 ≤ 0.1 噪声底，最大 ≤ 0.5 噪声底；
5. AtP 分数全部有限，每对排名表无重复。

闭环 `tool_ok`（smoke 是闸门，正式也要过）需要以下全部成立：
1. 每次运行完成，哈希核对通过，结果能由轨迹重算出来；服务端日志与客户端逐请求一致；
2. 切换步的物理哈希与阶段 1 相同；
3. **请求 1 的保真度**：程序在不改动时与 `Policy.infer` 的 L∞ 差，中位 ≤ 0.01，最大 ≤ 0.05。对 native、amp2 用 K/V 程序，对神经元臂用钩子程序；
4. **改动大小**：
   - native 没有改动；
   - 神经元臂每次请求、每层的改动范数与目标之差 ≤ 1e-3（相对）；
   - nrnrand2、nrnoutrand 与对应 S 臂逐层匹配，nrndir2 与 nrn2 逐层匹配；
   - amp2 同闭环；
5. 除 native 外，每个臂请求 1 的动作块都与不改动时不同；
6. 每个臂的指令都是 B。

只报告：native 与阶段 1 一致的比例；每臂耗时；请求 1 动作变化的中位；动作越界。

## 6. 读法

第 6 节状态：已冻结（2026-11-05，开环 smoke 之后、开环正式批次之前；冻结后读法和门槛不改。smoke 只用了初始布置 0、1，不在读数集里）。

**统计**：
- 开环：每格 = 一对 × 一个时点，用读数集的 10 个状态，报中位数和 bootstrap 95% 区间（按初始布置重抽，2000 次，种子 0）。
- 闭环：同闭环检验，按 SW 分支配对，按格分层 bootstrap（`closed_loop.paired`），用初始布置 2–19。

**N0 路径**（读数集，f = 0，每对取 ρ_mlp 的中位数）：
- `mlp_route`：每对 ρ_mlp ≥ 0.5；
- `attention_route`：每对 ρ_mlp < 0.3；
- `shared`：其余情况。
- 同时报告逐层的 ρ_mlp[l]、ρ_attn[l]。

**N1 稀疏度**（读数集，f = 0）：
- 每对的上限 c = ρ_mlp 的中位数。k* = K 中使 ρ_top(k) 的中位数 ≥ 0.5·c 的最小 k；没有就记为无。
- `sparse`：每对的 k* ≤ 1000（钩子神经元的 0.44%）；
- `distributed`：至少一对没有 k*（10,000 个、即 4.4% 都不够）；
- `moderate`：其余情况。
- 同时报告 ρ_rand(k*)，和前 10 名逐个替换的 ρ。

**N2 中途变淡**（读数集，格的划分同开环 R2）：
- 每个初始布置，γ = D_{k*}(f) / D_{k*}(f = 0)；
- 成功格：1→8 .25、.5、.75；失败格：7→8 .5、.75，2→9 .25、.5、.75。
- `neurons_fade`：每个失败格 γ 的中位 ≤ 0.8 且区间上界 < 1，同时每个成功格的区间下界 ≥ 0.9；
- `neurons_kept`：每个失败格的区间下界 ≥ 0.9；
- `mixed`：其余情况。
- 同时报告：每格的 ρ_top(k*)、ρ_mlp、ρ_attn，以及 ‖G‖ 和 D_all 的 γ。

**N3 充分性**（闭环失败格，90 个状态）：
- 增益 = nrn2 − native，特异性 = nrn2 − nrnrand2 和 nrn2 − nrndir2。
- `restores_switch`：增益 ≥ 0.15，增益区间下界 > 0，两个特异性区间下界都 > 0；
- `weakly_restores`：增益和两个特异性的区间下界都 > 0，但增益 < 0.15；
- `nonspecific`：增益区间下界 > 0，至少一个特异性区间下界 ≤ 0；
- `harms`：增益区间上界 < 0；
- `no_restore`：其余情况。
- 只报告：amp2 − native（重复闭环）；mlpall2 − native；nrn2 的增益占 amp2、mlpall2 增益的比例。

**N4 选择性**（成功格加起点格，108 个状态，同闭环 R5）：
- 改变 = nrn2 − native；
- `selective`：区间下界 ≥ −0.10；
- `damages`：区间上界 < 0 且改变 ≤ −0.10；
- `unclear`：其余情况。

**N5 必要性**（成功格加起点格，108 个状态）：
- 下降 = native − nrnout，特异性 = nrnoutrand − nrnout。
- `necessary`：下降 ≥ 0.15，下降区间下界 > 0，特异性区间下界 > 0；
- `weakly_necessary`：下降和特异性的区间下界都 > 0，但下降 < 0.15；
- `nonspecific`：下降区间下界 > 0，特异性区间下界 ≤ 0；
- `not_necessary`：其余情况。
- 只报告：native − mlpallout。

**N6 解释**（U 中每个神经元 24 题）：
- 一个神经元算"解释成立"，需要同时满足：正确率 ≥ 0.75，Wilson 95% 下界 > 0.5，比平凡基线高 ≥ 0.10。
- `interpretable`：U 中至少一半解释成立；
- `partly_interpretable`：至少 20%；
- `opaque`：其余情况。

**解读规则**（写在运行前）：
- **N0**：
  - `attention_route`：只给 MLP 换上 B 的值补不回多少，图像 token 上的 B 信息主要靠注意力直接从文字搬到位，MLP 神经元不是合适的单位。N1–N6 照常报告，但结论停在"注意力路径"，不说是神经元。
  - `mlp_route` 或 `shared`：MLP 神经元承担了可观的一份，往下读。
- **N1 `sparse`、N3 `restores_switch`、N4 `selective` 同时成立**：少量神经元就是一个充分且有选择性的修复位置，图像路的因果环节可以落到具体神经元上。
- **N5 `necessary`**：把这些神经元压回 A 的值，原本能换的切换就换不过去。它们对切换是必要的，不只是充分。
- **N3 `no_restore`，而 mlpall2 有增益**：MLP 这条路有用，但前 k* 名不够，效果分散在更多神经元上。
- **mlpall2 也没有增益**：amp2 的效果不能由在 MLP 上放大复现。它更可能来自注意力的写入，或者需要直接改 K/V。
- **N2**：
  - `neurons_fade`：这些神经元在失败格里不再区分 B 和 A，图像路变淡在神经元上看得见；
  - `neurons_kept`：它们仍在区分，变淡来自注意力那一份，或来自它们的写入在下游被抵消。
- **N6 `opaque`**：神经元能定位、能起作用，但说不清它们编码什么。结论停在电路层面，不说 Goodfire 的"干净神经元"在 π0.5 上成立。

## 8. 风险

- **ρ_mlp 不是"MLP 的份额"**：它是"注意力仍读 A 的文字、MLP 写出 B 的值"时补回的比例。MLP 的输入本来就靠注意力带来的信息，所以 MLP 和注意力的份额不能相加成 1。
- **ρ 只看第 12–14 层的图像 K/V**：神经元改动还会经双向注意力改到文字 token 和别的层，ρ 不计这些。动作上的 E 和闭环会把它们算进去。
- **AtP 是一阶近似**：π0.5 上归因可能不可靠。读数全用真实替换，AtP 与真实值的相关只报告。
- **bf16**：钩子里的改动用 float32 算，写回时舍入到 bf16。恒等式核对用 1e-3 的容差。
- **剂量**：nrn2 用 λ = 2，与 amp2 相同的"相对剂量"。但 S 只承担 ρ_top(k*) 那一份，对 W 上 K/V 的改动比 amp2 小。所以 N3 读成 `no_restore` 可能只是剂量不够，要和 mlpall2 一起看。
- **解释者和盲测者都是语言模型**：盲测者是新开的子代理，只看解释和题目，但不是独立的人。
- **范围窄**：一个检查点，LIBERO-Goal 三对，开环读数每格 10 个状态。
