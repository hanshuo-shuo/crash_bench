## 1. 问题与假设

**问题**：在换不过去的格里，如果把动作专家从图像 token 读到的"B 相对 A 的差"恢复到 t = 0 的大小，切换成功率会不会上升？

**假设 H**：图像路变淡是换不过去的原因之一。按 H，做两件事的结果应当不同：
- 沿 B − A 的方向放大，切换成功率上升；
- 换成同样大小的随机方向，切换成功率不上升。

**对立解释**：
- **读出侧**：动作专家中途换了读的位置或方式，信号放大了也没用（[方案](HIL_MECHANISM_IDEA.md)第 5 节的解释 2）；
- **物理可达**：这个状态下 B 本来就做不成，例如 Causeway 的 task islands（同上，解释 3）；
- **非特异**：任何扰动只要够大，都能把机器人从 A 的惯性里推出来，方向无所谓。随机对照就是为排除这一条。

## 2. 干预

**作用位置**：只改动作专家读到的前缀 K/V，VLM 自己的计算不动。
- **层**：第 12–14 层。f = 0 时，这个窗口只换图像组的 E 在三对上最一致（0.53 / 0.51 / 0.55）；第 14 层是三对共同的单层峰值。
- **token**：两个相机的有效图像 token（各 256 个，掩掉的第三个相机槽不算）。图像在前缀最前面，A、B 下位置相同，不需要重新做 RoPE 旋转。

**每次推理的计算**：同一帧画面上，
- 用当前指令 B 算一遍前缀，得到 K_B、V_B；
- 用切换前的旧指令 A 再算一遍，得到 K_A、V_A。

各臂把选定层、选定 token 上的 K、V 换成下表的值，其余照 B 的原样：

| 臂 | 选定位置上的 K、V | 含义 |
|---|---|---|
| native | K_B，V_B（λ = 1，什么都不动） | 原生 π0.5，和干预臂走同一个程序 |
| amp2 | K_B + 1·(K_B − K_A) | 放大到 2 倍：失败格的 γ 约 0.5，2 倍大致把差恢复到 t = 0 的大小 |
| amp4 | K_B + 3·(K_B − K_A) | 放大到 4 倍，看剂量关系 |
| rand2 | K_B + 1·‖K_B − K_A‖·r̂ | 随机对照，改动大小与 amp2 相同 |
| rand4 | K_B + 3·‖K_B − K_A‖·r̂ | 随机对照，改动大小与 amp4 相同 |

V 的处理与 K 相同。
- **随机方向 r̂**：每一层、每个 token、每个 K/V 头各抽一个单位向量，‖·‖ 是该向量自身的范数，所以每个向量的改动大小与 amp 完全一致。
- **随机数**：用状态自己的方向种子，与请求序号折叠后生成。rand2 和 rand4 用同一串方向，rand4 就是 rand2 的 3 倍。

**触发**：干预只在"指令被换"之后的运行里进行，旧指令 A 是已知的；不用 re-entry 位姿，也不用任何 B 的示范。不换指令时 A = B，差为 0，干预自动为空。所以"不换指令时 A 照常完成"由构造保证，不需要另测。

**噪声**：所有臂按 openpi `Policy.infer` 的方式从同一个 RNG 取噪声，RNG 在运行开始时重置到前缀种子（与阶段 1 相同）。同一状态的各臂，每次请求的噪声都相同；轨迹分岔之后，相同的只剩噪声。

## 5. 读法

第 5 节状态：已冻结（2026-11-04，smoke 之后、正式批次之前；冻结后读法和门槛不改）。

冻结前根据 smoke 加了两个只报告的项，见"描述性"的最后两条。读法、门槛和臂都没改。

**只用正式批次的初始布置 2–19。** smoke 的初始布置 0、1 只作描述，不进读数。

**C1 工具核对**（smoke 和正式都要过），`tool_ok` 需要以下全部成立：
1. 每次运行都完成，哈希核对通过，结果能由轨迹重算出来；
2. 切换步的物理哈希与阶段 1 同一 SW 分支相同；
3. 服务端日志与客户端逐请求一致：请求数、输入哈希、RNG 前后状态、动作块哈希；
4. 请求 1 上，干预程序在 λ = 1 时与 `Policy.infer` 的 L∞ 差：中位 ≤ 0.01，最大 ≤ 0.05；
5. native 臂每次请求的改动都为 0；amp 和 rand 臂每次请求的改动大小 ÷ ((λ − 1)·‖B − A‖) 与 1 的差 ≤ 0.001；
6. 每个干预臂在请求 1 的动作块都与 λ = 1 时不同。

只报告、不作门槛的项：
- native 臂与阶段 1 结果一致的比例（闭环对数值噪声敏感）；
- 第一个策略输入的哈希与阶段 1 相同的比例（EGL 渲染可能差 1 个灰度级）；
- 每次运行和每次请求的耗时；
- 动作越界次数。

**统计**：状态按阶段 1 的 SW 分支配对，比较同一状态在两个臂下的 b_done。差的均值和 95% 区间用 bootstrap 求，按格分层，在格内重抽状态，2000 次，种子 0。

**R4 恢复**：失败格，90 个状态。每个剂量（λ = 2、4）分别读：
- **增益** = amp − native；**特异性** = amp − 同剂量的 rand。
- `restores_switch`：增益 ≥ 0.15，增益区间下界 > 0，特异性区间下界 > 0；
- `weakly_restores`：增益和特异性的区间下界都 > 0，但增益 < 0.15；
- `nonspecific`：增益区间下界 > 0，特异性区间下界 ≤ 0；
- `harms`：增益区间上界 < 0；
- `no_restore`：其余情况。

λ = 2 是预先指定的主剂量（把差恢复到 t = 0 的大小），λ = 4 看剂量关系。两个都报告，不在事后挑。

**R5 选择性**：成功格加起点格，108 个状态。每个剂量分别读，改变 = amp − native：
- `selective`：区间下界 ≥ −0.10；
- `damages`：区间上界 < 0 且改变 ≤ −0.10；
- `unclear`：其余情况。

成功格和起点格分开报告，不作门槛。

**描述性（不作门槛）**：
- 每格每臂的切换数；
- 失败的运行里 A 完成了多少（失败是不是"继续做 A"）；
- 换成功时用的步数；
- 闭环里第 12–14 层图像 V 的 gap（‖V_B − V_A‖ / ‖V_B‖）：请求 1 的值，以及整局的中位数。
- 每格每臂，请求 1 的动作块相对 λ = 1 的变化（L∞ 中位数）。
- **amp2 对 rand4**（失败格，配对，同样的 bootstrap）。理由：rand 臂匹配的是 K/V 改动的大小，但在 smoke 里它对动作的影响小得多。请求 1 动作块的 L∞ 变化中位数：amp2 0.18，rand2 0.018，rand4 0.085，amp4 0.55。rand4 的 K/V 改动是 amp2 的 3 倍，对动作的影响也更接近 amp2。如果 amp2 胜过 rand2，却不胜过 rand4，就不能排除"只是动作被推得更远"这一解释。

**解读规则**（写在运行前）：
- λ = 2 读成 `restores_switch` 且 R5 `selective`：图像路变淡是换不过去的一个因果环节，而且可以有选择地补回来。这支持方案第 5 节的解释 1，可以作为 P5 修复的依据（P5 仍需单独批准）。
- 只有 λ = 4 读成 `restores_switch`：图像路有因果作用，但要过量恢复。这说明问题不只在 gap 的大小，读出侧的敏感度也降了。
- `nonspecific`：放大有用，但随机扰动同样有用。增益来自"把机器人推离 A"，不是图像路特有的；不能说图像路是原因。
- 两个剂量都 `no_restore`，而 C1 通过、改动确实发生：恢复图像路的差不足以让切换成功，失败要到读出侧（解释 2）或物理可达性（解释 3）里找。
- `harms` 或 `damages`：放大超出了模型正常的输入范围，报告剂量上限，不做解读。

## 7. 风险

- **放大可能超出正常范围**：4 倍时改动大约是 K/V 本身大小的一倍多，可能让动作失常。R5 和动作越界数会显示出来。
- **闭环对数值噪声敏感**：native 臂未必逐局复现阶段 1。所以对照用同一程序、同一批次里的 native，阶段 1 只作参考。
- **随机对照只在表示空间里匹配**：同样大小的 K/V 改动，随机方向对动作的影响约为 B − A 方向的十分之一（smoke）。所以特异性读法回答的是"在表示里改同样多，方向是否要紧"；在动作上匹配的对照只有 amp2 对 rand4 这一项，而且只作报告。
- **只有一个窗口、两个剂量**：如果读成 `no_restore`，只能说"这种恢复方式不够"，不能排除别的层或别的恢复方式。
- **范围窄**：一个检查点，两对失败任务，每格 18 个状态。
