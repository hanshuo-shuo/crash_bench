## 结论

预先写定的读法：

| 读法 | 范围 | 结果 |
|---|---|---|
| 开环工具核对 | smoke 和正式，240 个状态 | `tool_ok` |
| N0 路径 | 读数集 f = 0，三对 | **`mlp_route`** |
| N1 稀疏度 | 读数集 f = 0，三对 | **`moderate`** |
| N2 中途变淡 | 读数集，8 格 | `mixed` |
| 闭环工具核对 | smoke（闸门）和正式，1,200 次 | `tool_ok` |
| N3 充分性 | 闭环失败格，90 个状态 | **`nonspecific`** |
| N4 选择性 | 成功格 + 起点格，108 个状态 | **`selective`** |
| N5 必要性 | 成功格 + 起点格，108 个状态 | `weakly_necessary` |
| N6 解释 | 前 10 名的并集，23 个神经元 | **`interpretable`** |

- **新指令写进图像 token，几乎全经 VLM 的 MLP 神经元。**
  - 只把第 0–13 层图像行上的 MLP 隐藏值换成 B 的，第 12–14 层图像 K/V 上 B − A 的差就补回 91–94%（三对中位 0.914 / 0.919 / 0.940）。
  - 补回主要来自第 9–13 层。
  - 闭环里两个方向都成立（只报告）：
    - 失败格里，把全部 MLP 神经元沿 B − A 放大（mlpall2），切换从 20/90 升到 59/90，接近 amp2 的 67/90；
    - 原本能换的运行里，把全部 MLP 神经元压回 A 的值（mlpallout），B 是 0/108，机器人 103/108 把旧任务 A 做完了，尽管指令文字仍是 B。
- **但这一份分散在几千个神经元上，不是少数几个。**
  - 要补回一半，需要前 3,000 / 1,000 / 3,000 名（钩子神经元的 1.3% / 0.4% / 1.3%）。
  - 前 10 名只补回 0.045–0.070，单个头名神经元 ≤ 0.02。
  - 同层同个数的随机神经元，到 1 万个也 ≤ 0.05。所以排名是有用的，只是效果摊得很开。
- **闭环里，只改前 k* 名的作用小，而且方向不特异。**
  - nrn2 把切换从 20/90 提到 31/90，增益 +0.12 [0.01, 0.23]，约为 amp2 增益的 23%、mlpall2 增益的 28%。
  - 同层随机神经元（nrnrand2）20/90，与 native 一样，nrn2 比它高 +0.12 [0.02, 0.23]。
  - 同一批神经元换成随机方向（nrndir2）是 26/90，nrn2 只比它高 +0.06 [−0.06, 0.18]，区间跨 0，所以读成 `nonspecific`。
  - 换句话说：选中哪些神经元有影响，但在这些神经元上往哪个方向推，在 90 个状态上分不出来。
- **原本能做的不受影响**：nrn2 在成功格和起点格上是 107/108，native 105/108。
- **必要性只在一格里出现。**
  - 下降 native − nrnout 是 +0.148 [0.10, 0.19]，刚好低于预先定的 0.15，所以是 `weakly_necessary`；同层随机集压回去（nrnoutrand）是 105/108，与 native 相同。
  - 下降全部来自 1→8 .75 一格：nrnout 1/18，native 18/18，其中 17 次机器人改去做 A。其余 5 格 nrnout 是 16–18/18。
- **神经元在中途变淡，在失败格里看得见。**
  - 前 k* 名的 ‖h_B − h_A‖ 与 f = 0 之比，五个失败格的中位是 0.35–0.76，上界都 < 1。
  - 成功格 1→8 .5、.75 是 1.22、1.16；只有 1→8 .25 是 0.895 [0.839, 0.942]，下界没到 0.9，所以读成 `mixed`。这与开环 R2 的情形一样。
- **前 10 名的解释，在留出的初始布置上能预测激活。**
  - 23 个神经元里 17 个解释成立，平均正确率 0.80，平凡基线 0.52。
  - 解释大多是"对哪几条任务指令反应强"，即任务身份的特征。

**按冻结的解读规则**：
- **N0 `mlp_route`**：MLP 神经元承担了可观的一份，往下读。
- **N1、N3 都不是规则里的"少量神经元是充分且有选择性的修复位置"**：图像路的因果环节不能落到少量具体神经元上。
- **N3 读成 `nonspecific`，不是 `no_restore`**，所以"MLP 这条路有用，但前 k* 名不够"那条规则严格说不适用。只报告的数字（mlpall2 59/90，nrn2 31/90，mlpall2 − nrn2 +0.31 [0.19, 0.43]）指向同一个意思：效果分散在比前 k* 名多得多的神经元上。
- **N5 不是 `necessary`**：不能说这些神经元对切换是必要的。
- **N6 `interpretable`**：前 10 名大多能用一两句话描述。但它们各自只补回约 1–2%，说得清和起作用是两回事（见"能说什么"）。

## 能说什么、不能说什么

**能说**（π0.5 `pi05_libero`，LIBERO-Goal 三对，冻结读法）：
1. 在动作专家读的第 12–14 层图像 K/V 上，新指令与旧指令的差几乎都能由 VLM 第 0–13 层图像行上的 MLP 隐藏值写出来（ρ_mlp 0.91–0.94），主要在第 9–13 层。
2. 这一份在闭环里是起作用的（只报告）：
   - 全部 MLP 神经元沿 B − A 放大，失败格的切换从 20/90 升到 59/90，与在 K/V 上放大的 amp2（67/90）分不开；
   - 全部压回 A 的值，原本能换的运行一次也换不过去（0/108），机器人照旧指令做完（103/108），而输入的指令文字仍是新的。
   - 改动只在图像行上，但经双向注意力也会影响文字行在后面几层的表示。所以这说明新指令要经图像行上的 MLP 值才起作用，不说明文字行没用。
3. 它不稀疏：补回一半要 1,000–3,000 个神经元，前 10 名约 5%，单个约 2%。排名比随机好得多（同个数随机 ≤ 0.05），但效果分摊在几千个神经元上。
4. 在失败格里，这些神经元上的 B − A 差中途变小到 f = 0 时的 0.35–0.76，在能换的 1→8 .5、.75 不变小。"图像路在中途变淡"在神经元层面看得见。
5. 前 10 名大多能用一两句话描述它们对哪些指令反应强，并在留出的初始布置上让盲测者预测出谁更高（17/23）。

**不能说**：
- **不能说找到了少量的、可当修复位置的神经元。**
  - N1 是 `moderate`；
  - 闭环里前 k* 名只有 amp2 增益的四分之一；
  - 在同一批神经元上换成随机方向，与 B − A 方向分不开（N3 `nonspecific`）。
- **不能说它们对切换是必要的。** N5 的下降低于门槛，而且全部来自 1→8 .75 一格。为什么只在这一格，本批次没有查。
- **不能把"说得清"当成"起作用"。** 被解释的前 10 名各自只补回约 2%。
- **（11-07 更正）不能说这和 Goodfire 的"神经元已经干净"相反。** 那篇随笔（Cammarata，already-clean.goodfire.com）主张单个神经元大多只干一件事、读得懂，不主张一个行为只靠少数神经元；按这个意思，N6 的 17/23 与它一致。本报告的"分散"只在本方法下成立：
  - 排名目标是第 12–14 层图像 K/V 的补回（ρ），不是动作；
  - 一个神经元在全部图像行上合成一个单位（`neurons.py` 对图像行求和）；
  - 干预是放大或压回，不是删除；
  - 范围只有第 0–13 层图像行的 MLP。
  那篇文章里也有删 8–25 个神经元就改变 Qwen 答案的例子。按动作、按"神经元 × 图像块"重新排的补测（[方案](HIL_MECHANISM_UNITS.md)，[报告](HIL_MECHANISM_UNITS_REPORT.md)）显示，本报告的"分散"大半是方法造成的：

- **盲测的留出只在初始布置上**：指令、任务对和进度与写解释时相同。解释者和作答者都是语言模型。
