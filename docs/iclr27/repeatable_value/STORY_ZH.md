# 从“这次救回了”到“下次值得干预”

工作标题：**Beyond Observed Rescue: Evaluating Repeatable Intervention Value in VLA Policies**

这篇论文要回答一个直接的问题：机器人在某个状态换一种做法成功了，我们有多大理由相信，这是一项值得在未来执行中选择的干预？

## 读者应该记住的故事

恢复研究最终需要做一个执行前决策：继续原策略，还是付出接管代价。一次恢复成功提供了一个有用的案例；要把它变成选择监督，还需要知道原策略本来会怎样、换一批执行是否仍获益，以及成功是否只是跨过了某个截止时间。

CrashBench 让我们在同一决策状态实际执行不同选项，也让我们看到一个常被忽略的现象：同样继续 Base，重复执行的后果也可能不同。这提供一个直观的负对照——如果仅仅给两次 Base 执行换上不同的选项名字，评价器也报告了“最佳干预收益”，它测到的就包含执行后的选择优势。

这个故事的另一半同样关键：有些恢复真的保留下来。Detour 的 e18/e21 是成功案例；Refresh 的若干短预算“救回”则在 Base 多执行一两步后消失。我们通过同一套评价区分这两类结果，并进一步检验学习选择器有没有利用保留下来的机会。

论文的核心输出是对恢复机会更有用的判断：哪些只是这次赢了，哪些在重复执行中仍有净收益，哪些已经能由执行前输入选择。这个区分把方法开发从追逐一次成败，推进到寻找可利用的任务增益。

## 主文只保留四个证据对象

1. **开场实例与负对照。** 用 e15 的两次 Base 分叉说明单次比较为什么会改变“救回”的解释；用 e18/e21 保留真实恢复的存在。实例引出问题，全部来源的主表决定结论强度。
2. **真实与伪干预的并列表。** 同样的每臂重复数下，比较 A 选/A 评与 A 选/B 评。Base/Base 的伪选项明确标记为执行编号；完整重复的真实参考另列。
3. **截止曲线。** Refresh 展示 Base 追上；Detour 展示长时间才能完成的恢复。曲线上不重新选门槛，直接呈现时间与任务增益的关系。
4. **机会到选择的差距。** 展示完整来源贡献、fitting/calibration 支持和冻结 gate 的结果。保留正常任务损害，解释为什么少数救回没有变成整体方法胜利。

历史 wall probe、早期网络和工程修复进入背景或附录。正文不按项目时间线讲，也不把每次失败都写成一个独立贡献。

## 三个必须由结果决定的措辞

如果同批复用产生实质性的高估，并且独立估计能在新的执行中预测兑现结果，可以将“评价改进”升级为中心实证贡献。

如果偏差只在部分预算和接口中明显，主张就落在“区分不同的恢复收益”，保留稳定正例。不能把局部结果扩大成 VLA 恢复普遍被高估。

如果正收益在新来源保留，下一步方法问题是怎样识别它；如果缺乏正收益支持，则需要恢复技能或状态覆盖方面的新证据。两种结果导向不同研究行动。

## 正在推进的结果

Quest 作业 6240017 已完成三组既有面板的统一分析，执行提交
`1b852681342af34ab0fef6b36b96e9ae401c3f96`。Refresh 的100步单次选择收益为
A12.50→B3.12个百分点；Detour的440步完整重复参考为A6.25→B4.17个百分点。
收益有消退，也有保留，支持区分不同类型的恢复证据。

进一步的C执行块在作业6240307/6240316完成全部332分支，全部复用既有完整状态。
Refresh100步单次参考为A12.50→B3.12→C0，Detour440步完整重复参考为A6.25→B4.17→C5.21。
e18/e21在三批都保留正收益；e15则A有、B无、C再次出现。新执行前已经锁定全部选择和预测。

这一结果把中心故事改得更准确：一批执行既可能高估，也可能低估一个干预机会。
分开估计能改善这里的单次比较，但不能保证改善完整重复参考的逐来源预测。
论文贡献落在可检验地区分这些证据，而不把“复验一次”写成解决所有问题的保证。
