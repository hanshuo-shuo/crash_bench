## 1. 当前证据究竟卡在哪一层

| 层次 | 已有事实 | 尚缺的关键证据 |
|---|---|---|
| 有益干预存在 | 固定 Detour 的 e18/e21 在 9/9 主实验 A/B 中均救回；Refresh 有局部正负速度效果 | 事先定义的状态分布中，有益机会具有足够来源支持；两个选定锚点不能回答总体可学习性 |
| 收益可可靠测量 | 新 bundle、逐步输入、A/B 隔离、连续双预算读出已有实现 | 部分 Base 重复的终局仍变化；历史单次赢家不能当确定收益标签 |
| 执行前可选择 | 全输入模型在 e18 有正预测，说明并非完全没有局部信号 | calibration 没有兑现正收益，模型也误排正常损害点；未建立跨来源净收益 |
| 学习有额外价值 | 已加入强风险基线、简单规则及 DirectQ 等价核验 | Refresh 学习器未超过简单规则；Detour 全输入 gate 为全 Base |
| 在线能兑现 | 已有真实首次风险触发候选；历史有独立 fresh sequential closeout | 给定状态的离线优势不能直接转成从 reset 开始的完整接管策略；历史 Direct 24/24 Base、0/8 glass recovery |
| 值得成为主会贡献 | 风险、任务收益、预算和执行波动之间有可复核的诊断材料 | 仍需一个能改变领域认识或实践的发现，或一个有充分证据的新方法 |

### Refresh 已经提供的明确答案

候选复验的 B stale 100 步成功为 Base 23/36、Refresh 26/36；200 步为 33/36、31/36。100 步五次正向成功转换中，Base 全部在 101–102 步追上。因此这些例子主要支持截止附近的完成速度差，不能承担稳定任务救回主张。该面板的独立单位为八个物理来源。

固定收益 Ridge 的两种输入均增加完成代价，且原始成功由 Base 69/72 降到 67/72。事后提出的 age=1 规则只节省约 0.8 个来源等权完成代价步，其当前幅度和证据身份不足以承担新的效率方法主张。

来源：[Refresh 收束报告](../20260908/refresh_closeout/RESULTS_CHAPTER_ZH.md)、[直接收益学习](../20260908/direct_cost_learning/RESULTS_ZH.md)。

### Detour 的瓶颈比“网络没学好”更上游

本次直接读取 `all_terminal_records.csv`，核验 752 个双预算读出对应 376 条真实分支。440 步时 A 正收益锚点为 e15/e18/e21/e41；B 为 e17/e18/e21；交集只有 e18/e21，且都在 fitting 侧。四个 calibration 来源没有 B 正成功差锚点。

从完整 48 episode 表复算，440 步 Base 成功率 67.71%，候选均 Detour 39.58%，强 Risk→Detour 63.54%，全输入 gate 67.71% 且零干预。A 长预算参考为 71.88%，它使用实际 A 后果作选择，属于特权诊断。

代码中的全输入为 hidden PCA4、robot state 和 nominal action，经 Ridge 预测收益；校准仅最大化 H=220 成功并约束事故及正常保持。模型具有足够拟合秩，并非秩不足 fallback。e21 的正收益要到长预算才能出现；220 主目标与长恢复存在不匹配。这个限制需要保留，但改长预算不会自动解决正例仅在 fitting、正常任务损害和跨源排序问题。

因此目前不能仅根据全 Base 结果推断“所有输入没有信息”“学习不可能”或“只需放松门槛”。更准确的问题是：固定技能、目标预算、输入信息和来源组成，是否共同构成了一个有意义的选择学习问题？

来源：[Detour 主报告](../20260909/detour_benefit_gate/RESULTS_ZH.md)、[终局表](../20260909/detour_benefit_gate/evidence/all_terminal_records.csv)、[全部 episode 表](../20260909/detour_benefit_gate/evidence/all_episode_conditions.csv)、[门控实现](../../../crashbench/detour_benefit.py)。

### Recoverability 有机制线索，尚无可前瞻利用的机制

最新 48 分支探针中，e18/e21 的固定 R 成功在 0/3/10 推进后保留；失败对照 e27/e06 没有产生新的 R 成功。e18 在 +10 时 Base 也成功，干预必要性消失。e21 的标签受绝对截止与相同剩余预算影响。e27 的前段跟踪改善后，结果由超时变成下降事故。

控制器代码采用预设几何路径、位置控制和达到 leg cap 后推进阶段；它没有在每段转换前验证抓取成立或全臂无碰撞。现有观察与控制器适用范围有限相容，但尚不能识别关节构型、姿态、接触或目标设计中的哪一个是主因。执行后的阶段日志也不能直接用作执行前特征。

导师最有价值的技术判断是：这些案例主要揭示一个手写控制器的局部适用范围，还是能提炼成固定技能安全抓取与搬运的可预测条件？固定 R 失败仅说明该 R 在该预算下失败，不提供所有控制器都无解的证明。

来源：[微型实验结果](../20260909/recoverability/RESULTS_ZH.md)、[控制器实现](../../../crashbench/recovery.py)。

## 2. ICLR 主会定位的真实压力

以下是研究判断，不是会议的硬性录用规则。

1. **方法路线：** 核心缺口是跨来源、保留正常任务、超越强同条件基线的可部署收益。旧 matched-state 正结果仍可保留，但无法替代此证据；工程修复与更完整统计也不会自动提供它。
2. **机制路线：** 需要从解释已有轨迹走向对未见状态作出具体预测，并通过可控改变检验。e18/e21 的阶段图目前尚不能证明一般性物理边界。
3. **评估/实证路线：** 当前证据距离它最近。可研究单次分支、截止时间和运行波动如何改变恢复标签与方法判断，以及怎样评估可兑现的干预收益。需要证明这是有广泛影响的问题，并展示可复用的改进；单个实现缺陷或几个小模型失败还不充分。

“Risk is not intervention value”是正确的问题区分，但风险与动作价值在决策理论中本来就是不同对象。仅有概念区分或反事实命名，新意较弱。同样，单次事后选赢家的期望不小于执行前选期望赢家，是已有的选择效应；研究贡献应来自实际量化影响和有效解决办法。

本次核对的原始文献进一步限制了宽泛定位：

- [SAFE](https://arxiv.org/abs/2506.09937) 已研究从 VLA 内部特征做跨任务失败检测。
- [LIBERO-RECOVER](https://arxiv.org/abs/2609.05178) 已公开在 LIBERO 上构建 1,000+ 失败恢复场景的 benchmark。
- [B2FF](https://arxiv.org/abs/2606.09258) 已研究 recoverability-aware 的未来里程碑选择；其摘要明确使用与注入失败对齐的受控恢复时机，不能把它当完整自由在线触发问题已解决。
- [CoRe](https://arxiv.org/abs/2608.14822) 已研究冻结 VLA 的推理时反事实恢复。

这次仅核对上述原始页面与摘要，没有复现论文，也没有完成穷尽式新颖性审查。不能据此宣布这些方法会在本项目的事故协议下达到同样表现。

**第一，确定下一篇论文要让读者相信的唯一核心命题。** 我目前会优先讨论“干预收益的可信评估及其可预测性”这条实证路线，因为它最接近已经成立的证据。同时请导师明确：怎样的中心发现才足以让这个问题值得主会关注，哪些现有材料应退为附录？

我会直接问：

> 如果删掉我们的方法名称和全部工程投入，仅看这些结果，最值得发表的未知问题是什么？您认为最有潜力的是恢复方法、物理机制，还是恢复评价的可靠性？请选一个主要方向，并指出一张什么样的结果图会显著改变您的判断。

**第二，请机器人控制方面的专家帮我们判断技能本身是否足以支撑选择研究。** 需要一起看 e18/e21/e27/e06 的完整动作、关节/接触证据和控制器目标。若主要是固定路径与初始姿态不匹配，就要先评估恢复原语的覆盖能力；若存在可泛化且可感知的前置条件，再考虑将它变成输入和方法。这个判断比继续试几个预测头更能决定项目方向。

**第三，为一个能区分解释的实验约定投入和决策后果。** 先写明竞争假说、可见输入、预期结果、来源支持及预算；成功或失败都对应下一步判断。独立来源的规模应依据效应和不确定性设计，不把增加同源重复当扩大分布。若进入方法路线，需要获得可靠恢复技能、合适来源或机器人领域合作中的至少一项实质帮助；GPU 预算本身不能替代这些资源。
