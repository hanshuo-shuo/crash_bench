# Prospective execution-block replication of frozen value forecasts

## Why this next experiment

Quest analysis 6240017 found a 9.38 pp A-to-B decrease for one-shot Refresh selection
at 100 actions, but only a 2.08 pp decrease for full-repeat Detour selection at 440;
the latter retained 4.17 pp gain. Same-policy pseudo-options also generated apparent
gains, with orientation dependence. These results support a heterogeneous measurement
question, not a presumption of universal or large inflation.

The user's 2026-09-13 instruction authorizes advancing the paper with Quest experiments.
We narrow the feedback's proposed next study to **one new C execution block on the two
complete existing panels**. This directly tests previously locked forecasts without
mixing changed physical source composition into an execution-repeat question. It is
smaller than a new-source A/B/C collection and does not expand the benchmark or open D8.
It cannot establish generalization to new physical sources or a mature recovery method.

  pending proposal. Same original 220/440 absolute episode budgets for Detour and

  Full traces go to unique project-storage directories, small outputs under results/repeat_value.
- Missing bundle, checksum mismatch or unfinished branch stops that job. Do not replay
  completed branches, swap states, change budgets or interpret partial output as full results.
