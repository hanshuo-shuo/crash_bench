# 新来源结果：先建立可用恢复机会，再学习如何选择

十二个预先固定的新物理来源已在 Quest 完成 A/B/C 三批执行：每批 128 条，
共 384 条实际分支、36 个条件单元。全部来源保留，控制器、触发器、预算与
历史 gate 均未修改。主指标为包含前缀与恢复动作的 episode 440 步安全任务成功。

**最重要的结论是：旧来源上的真实救回案例仍然成立，但本次未筛选的新初始
场景没有建立可重复的正收益支持。当前不值得优先继续扩大选择模型。下一步
需要加强恢复能力及其状态覆盖，并用独立外部机制检验这一解释。**

## 2. 为什么这更像技能与状态支持问题

| 条件（各十二来源） | C Base 成功 | C AlwaysDetour 成功 | 差值 |
|---|---:|---:|---:|
| On-path glass | 45.83% | 16.67% | −29.17 pp |
| Off-path glass | 62.50% | 16.67% | −45.83 pp |
| No glass | 91.67% | 50.00% | −41.67 pp |
| 三条件合计 | 66.67% | 27.78% | −38.89 pp |

十一条名义 authoring 轨迹在 220 步内成功；无玻璃的 Base 在 C 也维持较高
成功率。问题不能简单解释成“新场景里所有策略都不会做任务”。Detour 可以
完成部分任务，却没有在 C 的任何一个条件单元中比继续 Base 多完成任务。

这一检查覆盖全部 36 个单元，包含 A 没有选中的状态；不是仅由低参考收益
反推机会不存在。C 仍然只有每臂两次，不能据此证明未知期望收益或所有恢复器
的能力上界。[完整两臂支持](evidence/analysis/arm_support.csv)。

具体来看，主参考只选择 no-glass 的 n05：A 中 Base 一次成功、一次失败，
Detour 两次成功；B/C 中两臂都两次成功。On-path 的 n06/n12 在三批中都有
Detour 完成，但 C 的 Base 也全部完成。n06 的正差只在 B 出现，A/C 都为零。
这些案例直接说明：恢复动作成功、干预确有必要、收益能够重复，是三件事。

AlwaysDetour 在 C 的成功差区间为 [−54.17,−22.22] pp；九个来源的净贡献
为负。它损失 38.89 pp 的 Base 成功，并引入 5.56 pp 的新事故；同时整体
事故率略降 1.39 pp。只优化事故减少会掩盖严重的任务损害。强风险参考在 C
为 56.94% 成功，原 gate 与 Base 均为 66.67%。

## 3. 这次实验能与不能改变什么

新来源没有按名义成功或固定动作事故筛选。旧 Detour 面板来自成功／危险
筛选过的资产，两个面板不属于同一来源构造。因此，不能把差异全归给来源
新旧、控制器或测量，也不能合并成一个更大的确认样本。

四个条件在零模型调用、零计入任务动作时记录终止：n01/n07/n13 为 off-path，
n18 为 on-path。它们在所有选项中保留同一个 setup 前缀结果，没有虚构重复
分支，也不能将这些零步事件归因于 Base 或 Detour 的决策。来源构造与动作
执行的这一区别必须随结果保留。

这轮不是“大幅真实干预高估”的强证据：真实主参考的 A−C 仅 1.39 pp。
伪选项的 8.33 pp 表观收益说明评价仍可能制造假机会；真实两臂的完整支持
则说明当前技能／状态组合不足以建立新的选择问题。两条发现应同时呈现。

旧来源 C 的 Detour +5.21 pp、e18/e21 的三批保留，以及 Refresh 的截止
附近加速均保持原样。论文主线因此变得更具体：评价应区分加速、重复救回、
正常损害和机会支持；这些结论引向不同的后续研究，而非统一归为“测量幻象”。

## 4. 下一项真正有价值的投入

先接通一个已有能力依据的外部恢复机制，再在其原生支持的失败状态类型上
确认相对自身 Base 的净收益。随后才检验相同的 A 选／B 估／C 验及来源支持。
SPR 的公开学习回退接口已通过两次查询的工程检查；更强但接入较重的 VoLoAgent 也
已核实公开代码。接口成功不能记作恢复性能验证。
[外部资产与贡献边界](../external_recovery/ASSESSMENT_ZH.md)。

导师／Pro 最有价值的帮助，是判断怎样的外部正对照能使这里的发现超出
两个有限的恢复接口，并为主会读者提供足够强的实证问题。继续增加预测头、
放松门槛或在这十二个已暴露来源上搜索漂亮结果，都不会直接解决该缺口。
