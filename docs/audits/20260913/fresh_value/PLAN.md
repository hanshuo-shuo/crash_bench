# Fresh-source decision probe following the prospective C result

The user asked on 2026-09-13 to continue in Pro's direction using this round's
findings. This entry makes that next bounded paper-development action concrete:
12 new reset sources, three conditions and at most 432 paired branches on Quest.
It is a prospective development/transport probe, not a new D8 confirmation or a
benchmark expansion. All historical experiments and the just-completed C blocks
remain frozen. No controller, learned gate or threshold is tuned in this study.

## Question and decision

Existing-state C preserved Detour's full-repeat 440-action reference gain
(A 6.25, B 4.17, C 5.21 percentage points), but concentrated its positive support
in fitting sources. Refresh showed a different, largely deadline-sensitive
pattern. The next question is whether the fixed Detour interface provides
repeatable positive opportunities on previously unseen physical reset sources.
We do not assume that independent B estimates must outperform reused A estimates.

Primary: freeze each state's privileged A choice using two executions per arm at
absolute episode H=440, then compare its A, B and C gains. The primary forecast
comparison is the paired source mean of
`(g_A - g_C)^2 - (g_B - g_C)^2`. Also report aggregate forecast errors, success,
accidents, lost Base successes, new accidents, intervention rates and all sources.
Five percentage points remains a practical investment heuristic, not a
significance criterion or an ICLR acceptance threshold. Twelve sources provide
a bounded decision experiment, not reliable power for small differences.

Secondary, frozen before execution: H=220; one-shot selection/evaluation;
Base/Base pseudo-options and their swapped-index sensitivity; the unchanged
historical Base, AlwaysDetour, RiskDetour and BenefitGate; and both arms at every
state, including states the A reference did not select. No C-based choice of
headline estimator or favorable horizon. Source bootstrap: 5,000 draws, seed
20270913. C has only two repeats/arm and is not exact ground truth.

## Source population and authoring

Use LIBERO-Spatial task 0, with twelve predeclared reset seeds 2027091400–1411.
Call the existing fresh-reset API, not the finite historical default-init pool.
Materialize all twelve states and check their hashes and object-scene fingerprints
against the identity-only exposure/split records, and against each other, before
any policy rollout. D8 outcome files are never opened. Save exact state bytes and
source XML. All attempts remain registered in this experiment's source manifest.

For each fixed source, collect at most one 220-action nominal no-glass authoring
trace using the same OpenVLA checkpoint. This trace provides an EEF path for the
existing arclength placement routine. Retain nominal successes and failures;
there is no source replacement, fixed-action accident screen, recovery-success
screen or repeated geometric proposal search. Cycle requested path fractions
0.48/0.54/0.60/0.64 three times. Use the existing backward clamp for 0.12 m target
clearance, radius 0.028 m, half-height 0.060 m, density 400; off-path control
offset 0.20 m with alternating sides. No glass is the third condition.

This is deliberately an unscreened fresh-reset population. The historical
Detour panel came from nominal-success/hazard-screened placement assets. A change
in prevalence across these panels cannot by itself be attributed to measurement,
source novelty or recovery skill. Report the populations separately; do not pool
their scores or call this an identical-distribution confirmation. “On-path” means
placed on the authoring EEF path, not guaranteed collision during a new policy run.

If reset, source isolation or placement construction fails, record the attempt
and stop before any paired branch. Do not silently replace it or manufacture a
task-failure label for an operational failure. A repaired attempt needs explicit
accounting of what executed; the runner has no automatic resume or retry.

## A/B/C isolation and budget

Author all sources/geometries and all 36 candidate prefixes before any paired
recovery outcome. A, B and C each run in a fresh process in the same A100 job.
Every phase restores the same complete per-state bundle and original policy RNG;
no seed change is claimed to randomize greedy decoding. Preserve systematic
process/block effects instead of calling them IID noise. Alternate Base/Detour
execution order within each two-repeat block. A traverses episodes ascending,
B descending, C with a fixed 12-episode rotation.

After A exits, write `freeze_A.json` with all choices and input hashes, before B
starts. After B exits, write `forecast_AB.json` with all source forecasts and
hashes, before C starts. The final analyzer checks this ordering, distinct PIDs,
identical GPU/software/commit, complete arm coverage and unchanged A/B forecasts.
Do not inspect partial outcomes to alter the run. Progress logs report counts.
No-candidate and candidate-before-accident episodes stay in the denominator as
shared prefix outcomes; no artificial repeated branches are invented for them.

Maximum: 12 nominal authoring rollouts, 36 evaluation prefixes, 432 paired
branches; A100 × 1, 8 CPU, 64 GB, 4-hour Slurm cap, account p33100/gengpu. Output
is a new commit/job-specific folder under project storage. Raw traces stay there;
compact records, locks, provenance and analysis are returned to the repository.
Entry: `setup/fresh_value.sbatch`. No automatic source extension after this job.

## Consequences for the paper

If multiple new sources retain positive C benefit, the story gains evidence for
a real recovery opportunity despite the frozen learned gate's failure to use it.
If nominal execution succeeds while R rarely completes, coverage of the fixed
recovery interface becomes the sharper bottleneck. If A optimism predicts the
wrong C decision and B corrects it, quantify the decision change. If outcomes or
source intervals are ambiguous, retain that result and do not force an
“all recovery gains are artifacts” narrative.

Independently verify one external method's actual code/checkpoint/interface
availability. External literature claims are not a completed replication, and
this small source probe alone does not remove the weak-controller objection.
