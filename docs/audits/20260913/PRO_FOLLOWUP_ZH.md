# CrashBench：完成 Pro 建议后的下一次研究决策

这是新一轮结果材料；最初的导师审查及其后反馈均保持原样。希望讨论的是
下一项能增强论文中心发现的工作，而不是再列一组泛泛的实验建议。

## 现在最值得记住的三个事实

**旧来源上，收益既会消失，也会保留。** 332 条前瞻 C 分支全部完成。
Refresh 单次 100 步参考为 A12.50→B3.12→C0 pp；完整重复 C 的 +2.34 pp
来自一个正贡献来源，其 Base 在 105 步内全部追上。Detour 完整重复 440 步
参考为 A6.25→B4.17→C5.21 pp；e18/e21 三批都保留，e15 在 B 消失后于 C
重现。来源级预测并非 B 一贯更好：完整重复 Refresh100 更差，Detour440
持平。[旧来源结果](repeat_value/RESULTS_ZH.md)。

**新来源上，恢复完成能力没有转化为重复净收益。** 十二个预先固定的新
reset、三条件、独立进程 A/B/C，完成 384 条实际分支。主参考为
A1.39→B0→C0 pp，唯一选择为 no-glass n05；B/C 中 Base 已全部成功。
全部 36 个条件单元在 C 都没有正的 Detour−Base 成功差，包括 A 未选中的
状态。On-path Detour 在两个来源完成，但 C 的 Base 也都完成。
[新来源结果](fresh_value/RESULTS_ZH.md)。

**本面板尚未建立稳定的互补收益支持。** 新来源 C 的 Base/AlwaysDetour 为
66.67%/27.78%，无玻璃为 91.67%/50.00%；AlwaysDetour 损失 38.89 pp 的
成功并增加 5.56 pp 新事故，尽管净事故率略降 1.39 pp。原 gate 全部 Base。
这比“再把选择头做大”更上游。与此同时，伪选项两种编号的 A 收益为
2.78/8.33 pp，C 都为零，评价问题也确实存在。

## 这些结果如何修正原中心命题

我不会再将“独立估计普遍更好预测未来收益”作为已经成立的主张。
真实新来源主参考的 A−C 只有 1.39 pp，未达到预先约定的 5 pp 投入尺度。
不能将伪选项的大变化移作真实恢复的高估幅度，也不能将所有不一致都算作
评价框架成功。

现在更接近数据的中心问题是：**怎样识别一种恢复操作对原策略有可重复、
能延伸到目标状态分布的互补价值？** 截止附近加速、真正救回、正常损害和
机会不足，对应不同的下一步。论文已有相反的具体案例，以及预先锁定后
真正执行的验证；仍缺一个能使发现超出当前两个有限接口的外部机制。

必须保留两点边界：旧 Detour 来源经过成功／危险筛选，新来源未筛选，
二者不能直接混成同分布确认；四个新条件在零模型调用时记录 setup 终止，
完整保留为共享结果。C 每臂两次也不提供未知期望收益的精确真值。

## 已经核实的外部路径

SPR 的官方代码与公开 Spatial 权重已经核实，并建立了独立运行环境。
普通任务与学习回退指令的两次接口检查均已通过；原始输出和截断边界在
[外部机制报告](external_recovery/ASSESSMENT_ZH.md)。原论文完整模型相对
去掉 Rewind 的平均增益约 1 pp，Spatial 对应 92.4%/92.6%；它有真实接口，
但不能因此称为该子集上的强恢复正对照。

VoLoAgent 已有公开物理工具恢复代码，但需要更完整的感知、抓取／放置及
编排服务，接入更重。B2FF／CoRe 仍未核实可直接运行的官方完整包。
ReCoVLA 等提供额外合作方向，资产边界也已记录。此处是可用性审查，
不是任何外部恢复性能的复现认证。

## 最需要导师／Pro 帮助解决的决定

我的优先选择是：下一轮集中到一个外部恢复操作，先在其原生支持的状态
类型上建立相对自身 Base 的正价值，再做固定选择的重复检验。把另一个
控制器直接移到陌生玻璃场景，然后发现它也失败，不能有效排除“技能与
状态覆盖不足”的反对意见。

请基于这些完整结果作出一个明确判断：

> 现有“恢复能力与干预必要性错位”的发现，是否值得升级为 ICLR 实证论文
> 的中心问题？如果还缺一张决定性图，请具体给出这张图应该比较什么、
> 哪个已有代码／权重／原生失败资产的外部方法最适合，以及哪种结果会
> 实质改变对恢复方法的判断。SPR 是否足以承担这个角色，还是更应该争取
> VoLoAgent、B2FF／CoRe 作者或机器人控制合作者的可运行资产？
>
> 请同时指出：如果外部结果稳定保留净收益，下一步应研究怎样识别这些
> 机会；如果仍无支持，哪项技能或状态条件必须先改变。不要只建议扩大
> 网络、重复数或放宽门槛，也不要把任何一种结果都包装成同样的成功故事。

英文正文已整合上述证据并使用官方 ICLR 版式。当前最有价值的外部帮助是
中心命题判断，以及能提供互补恢复能力和原生失败状态的合作资源；GPU
已经能把一个明确的小实验运行到底，但不能替代这两项研究条件。
