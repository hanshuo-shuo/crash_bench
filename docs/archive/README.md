# Legacy document archive

These files are dated snapshots retained for research provenance. They are not
current project truth sources and may contain superseded claims, plans, commands,
or links that reflect former repository locations.

Use [CURRENT.md](../CURRENT.md), [PAPER_PLAN.md](../PAPER_PLAN.md),
[CLAIMS.md](../CLAIMS.md), and [EXPERIMENT_INDEX.md](../EXPERIMENT_INDEX.md) for
the current state. Frozen supporting protocols are in the
[appendix](../appendix/README.md).

## Archived groups

- `REPORT.md` and `OVERVIEW.md`: historical result narratives.
- `STRATEGY.md` and `motivation.md`: early framing and literature strategy.
- `PHASE1.md`: original wall-pilot implementation note.
- `REPO_AUDIT.md`: pre-refactor repository audit from 2026-07-17.
- `P0_HANDOFF_20260726.md`: detailed E12/P0 execution handoff.
- `SETUP_README_20260812.md`: the former chronological setup and experiment
  guide, replaced by the scoped current `setup/README.md`.
- [glass_recovery_20260812/](glass_recovery_20260812/README.md): superseded E14/
  E15 main plan, Pilot A/B/C timeline, D/E/F gates, restore/hash/Slurm notes, and
  the illustrated progress audit.
- [preliminary_reports/](preliminary_reports/README.md): dated DOCX reports that
  are not current paper artifacts.

The code and tracked JSON associated with some archived documents intentionally
remain at their original paths. Tests, manifests, and provenance records bind
those paths; their legacy status is recorded in
[SCRIPT_INDEX.md](../SCRIPT_INDEX.md).

Place future superseded documents here rather than creating another competing
root-level plan.
